## 1. 目标在框架里是什么

框架的链（全部上游已证，本页只组装，**不新增物理**）：

| 环节 | 内容 | 上游出处 |
|---|---|---|
| **SLS6** | **引力 = 空间流动的非均匀性** | 公设层 |
| **GCA2** | 命题「**A 内引力关闭**」⟺ **Q_A = 0**（A 内流动起伏被抹平） | GravityControl |
| **PA3** | 双流形叠加：C = C₁ + C₂（两股流的空间场线性相加） | PlasmaAntiGravity |
| **DR2b** | 反向环流抵消：Γ(v)+Γ(−v)=0 ⟹ **\|Γ_H\| = \|Γ_Cu\|、反号** | PlasmaDynamics |
| **MUFC** | μ ← μ + η(1−μ)，**η = 抹平进展 = 1 − Q_A(v)/Q_A(v₀)** | MuFieldCoupling |
| **AMC1** | **m_eff = s(1−μ)** ⟹ 引力响应按 (1−μ) 缩小 | MassCancellation |

```text
Q_A(C) = Σ_{i∈A} |C_i − C̄_A|²                        （判定泛函；越小 = 引力越关闭）
η      = 1 − Q_A(C_Cu + C_H) / Q_A(C_Cu)              （加 H 环买到多少抹平）
μ_n    = 1 − (1−η)^n ；  引力响应 (1 − μ_n) = (1−η)^n
```

环流的空间流取**涡丝 Biot–Savart 律**（与磁场同形式，系数 Γ/4π 代替 μ₀I/4π）；
Γ 被 DR2b 锁成一对 ⟹ **环流速度不是自由参数**（v_H·R_H = v_Cu·R_Cu）。

## 2. 结果（数字都在 `runs/twoflowring_gravity/report.json`）

### 2.1 地基（决定性）

**同半径 + 反环量**的两环，其空间流**精确抵消**：

```text
Q_A(抵消对) = 0.000e+00      vs      Q_A(单 Cu 环) = 3.688e+02      ⟹ η = 1.000000
```

⟹ 「反向环流抵消」（DR2b）在**流场**上成立；η=1 时按 TD12 **一步 μ=1**，A 内引力关闭。

### 2.2 ★ 按 FRC 挑的几何给不出引力关闭

已定设计（R_Cu = 0.60 / R_H = 0.35，即**为场反位形而挑的半径差**）：

```text
Q_A(单 Cu) 3.6875e+02  →  Q_A(Cu+H) 7.9407e+03      η = −20.53  < 0
```

加 H 环反而让目标区空间流**更不均匀** —— 该几何**一点引力关闭都没有**
（单 H 环自己 Q_A = 1.105e+04，两环一起 7.94e+03：确实在抵消，只是远远不够）。

### 2.3 η(R_H) 是单峰，峰在 R_H = R_Cu

| R_H [m] | 0.48 | 0.50 | 0.56 | 0.58 | **0.60** | 0.62 | 0.70 | 0.84 |
|---|---|---|---|---|---|---|---|---|
| η | −0.008 | +0.417 | +0.943 | +0.988 | **+1.000** | +0.991 | +0.856 | +0.582 |

⟹ **径向匹配是流抵消的充要条件**。

### 2.4 容差（本页对设计系统最有用的一条）

| 方向 | η ≥ 0.5 | η ≥ 0.9 |
|---|---|---|
| **径向** \|R_H − R_Cu\| | **≤ 0.240 m**（= 40% of R_Cu） | ≤ 0.060 m |
| **轴向**分离 d | **≤ 0.05 m** | — |

轴向细扫 η(d)：0.05 → **+0.787**、0.10 → +0.233、0.20 → −1.168、0.50 → −2.938
⟹ **轴向共面性比半径匹配苛刻得多**（η>0 大致要 d ≲ 0.13 m）。

### 2.5 引力关闭曲线

达 μ = 0.99（上游工程表：τ_E ×10）所需次数：**η=1 一步到 μ=1**；否则 1.0 / 2.0 / 6.6 / 20.6
（η = 0.99 / 0.9 / 0.5 / 0.2）⟹ **η > 0 是硬门槛**，但 η 的精度不苛刻。

## 3. 与本仓已有的判据/门的关系

- **`clearance` 罚项 / G23 可造性门** 管的是「导体面 ↔ 中心元胞」的净空与几何可造性；
  本页是**另一种几何约束**：两个反向环流的**半径与轴向位置必须对齐到容差内**才能产生引力场。
  两者**口径不同、不可互相冒充**，但都是"几何必须是可造的"这一类 —— 接进打分前必须先把口径统一。
- **方向修正的后果要写进设计规则**：半径**不该按 FRC 挑**（FRC 要不同半径，引力要同半径）。
- 本页**尚未接进** `internal/design` 判决层，也**不进任何世界**（进动力学 = 新增物理，协议明文禁止）。
  要变成门须走上游/本仓的契约变更流程（先冻 `docs/design-layer.md` → 编译期签名锁 → 锚点重发）。

## 4. 死法（可判）

| 死法 | 判据 | 现状 |
|---|---|---|
| 半径不匹配 | \|R_H−R_Cu\| > 0.24 m ⟹ η<0.5；> 0.42 m ⟹ η<0 | 已扫（η=0 在 R_H ≈ 0.48） |
| 轴向分离过大 | d ≳ 0.13 m ⟹ η ≤ 0 | 已扫（0.20 → −1.168） |
| 环量不比 | \|Γ_H\| ≠ \|Γ_Cu\| ⟹ 抵消不完整 | DR2b 锁（非对称情形未扫） |
| 流模型失效 | 若真实空间流不是涡丝律，η 的数值要重算 | **未做**（见 §5） |

## 5. 诚实边界

- **环流 ⟹ 空间流**是**结构对应层**（标准涡丝速度律）；流场**绝对幅度 v 不由框架定**（只有比值被 DR2b 锁）
  ⟹ 本页算的是**几何效率**，不是时间尺度；
- **「η = 抹平进展」按 MuFieldCoupling 原文是模型选择**，不是从物理推出的；
- **抹平功率从哪来 = 上游第二输入缺口（档 3，未变）**；
- 目标区 A 是**口径**（r ≤ 0.30 m、\|z\| ≤ 0.26 m），η 随 A 的形状/大小变（**未扫**）；
- 涡丝律在导线附近有近场奇异性（A 贴环时数值要另处理）；
- **无新物理预言**；不含等离子体动理学/MHD；不含 μ 的主动产生机制；
- 上游数字**不进源码常量**（房规）；上游目录不在时本页只能当历史记录读。
