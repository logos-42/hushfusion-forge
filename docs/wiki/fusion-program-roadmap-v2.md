# 可控核聚变计划 v2

## 0. 计划的边界与总原则

这不是把火箭制造经验直接类比成聚变物理，也不是把“可重复制造”当成物理证据。
本版只借用一种工程组织方式：把复杂系统拆成可测的需求、可替换的模块、可重复的工序和可审计的迭代数据；所有聚变结论仍由
`/Users/apple/Downloads/lean/ProjectionPhysics` 的公式、Lean 定理和数值验证给出。

计划的真正目标是：**制造一个能反复制造、反复测量、反复淘汰下一代聚变构型的系统**，而不是先押注一台不可拆、不可复用的终局装置。

必须同时遵守四条边界：

1. `ProjectionPhysics` 中已证的代数恒等式、尺度关系和数值锚点可以作为计算输入，但不能被表述成已验证的聚变机制。
2. Forge 当前是线圈/真空静磁设计搜索器，不是等离子体平衡、有限 β、输运或发电量证明器。
3. μ 的主动产生机制仍是第二输入缺口；D1 只是判决它是否存在，不能预先把它当成设备能力。
4. 每一项制造优化必须绑定物理量、误差预算、寿命/循环数据和失败处置；没有证据就标记为 `[缺口]`。

## 2. 从火箭制造方法中吸收什么

这里使用的是五步工程工作法，而非对具体火箭结构作未经验证的照搬。

### 第一步：让需求不再含糊

每个需求必须写成“量 + 单位 + 测量方法 + 容差 + 失效动作”。例如：

- 不是“高场”，而是 `B_peak`、场均匀性、脉冲/稳态模式、探头位置和不确定度。
- 不是“可复用”，而是循环次数、拆装次数、性能保持率、检修时间和报废判据。
- 不是“用不锈钢”，而是牌号、温度、磁导率、屈服/疲劳、焊缝、真空放气、辐照和激活条件。
- 不是“可制造”，而是净空、绕组包络、可达公差、无损检测覆盖率、装配顺序和首件验证。

第一道门：需求未量化，不能进入采购和终局设计。

### 第二步：删掉不必要的零件和工序

每个零件必须回答“它解决哪个物理约束或检测风险”。优先删掉：

- 只为补偿未定义目标函数而存在的线圈/传感器；
- 把一次性分段压缩复杂度带入稳态方案、但没有对应判决量的部件；
- 无法拆换、无法检测、只为单一实验构型服务的永久集成件；
- 把 `FC5` 稳定性问题误当成更高 μ 就能解决的附加系统。

删除必须经过“物理影响—制造影响—诊断影响”三联审查，不能为了少零件而删掉安全壳、真空边界、屏蔽、互锁或独立测量通道。

### 第三步：简化并优化，而不是先追求极限性能

先做可拆卸、可测量、可更换的基线构型，再逐项提高 `B`、β、μ 或功率。优化目标至少包含：

`物理性能 + 可造性 + 可检修性 + 循环寿命 + 诊断可观测性 + 材料/能量账本`

Forge 的下一代评分必须把净空和 `buildable` 从报告门变成搜索约束；在此之前，任何“机器最优”只能叫候选场构型。

### 第四步：缩短循环时间

把设计—制造—测试拆成小型首件闭环：单个线圈模块、单个真空接口、单个诊断盒、单个可替换内衬，先测再扩展。
每一轮只允许改变有限变量，并保存：设计谱系、材料批次、装配工序、测量原始数据、失效模式和下一轮修改理由。

节拍指标不是“更快建终机”，而是 `Time-to-validated-next-prototype`：从需求冻结到下一件通过物理/制造/诊断门的时间。

### 第五步：自动化重复动作，保留独立复核

自动化适用于参数化设计、场计算、误差传播、BOM 生成、测量采集、回归比对和寿命统计；不自动化未经验证的物理推断。
所有自动判定保留独立 oracle、人工抽检和可回放记录。Forge 的 registry 是制造知识库的雏形，但只有接入真实测量后才可以计算真实硬件学习曲线。

## 3. 新装置架构：模块化、可复用、可回收

采用“固定基础设施 + 可更换实验芯盒 + 外置场源/诊断”的三层架构：

1. **固定层**：真空、屏蔽、支撑、低温/电源接口、安全互锁和数据采集骨架。固定层不追求一次铸成终局，而追求可检测、可维修和接口冻结。
2. **芯盒层**：燃料区边界、内衬、双流环候选件、局部线圈和探针。芯盒按实验模式快速更换，避免辐照、热循环或污染后报废整机。
3. **场源层**：RMF/形成线圈、功率电子、传感器和控制器。按 `B`、频率、μ 假设和稳定性门选择不同模块，不让一种材料路线锁死全系统。

“一次压铸”只作为制造候选，不作为默认架构：

- 可以考虑对低风险、非真空、非高应力的重复支撑件做一体化铸造，以减少接口和装配时间；
- 真空承压边界、高场受力件、低温关键件和辐照暴露件必须先通过热—结构—疲劳—真空—检修联合分析；
- 一体件必须保留可检测的基准面、检修口、无损检测路径和失效隔离；无法检测的整体件不算“简化”。

## 4. 材料与循环利用方案

### 4.1 材料计算顺序

材料选择按以下顺序做，不按“某材料很先进”倒推：

1. 用 `PF3/FC1` 由 `n、T、β` 反推 `B_min`；
2. 用 `PF5/PF7/FC8` 计算磁压、环向应力和场上限；
3. 加入热循环、脉冲电磁力、疲劳、真空、辐照/激活、低温和电阻损耗；
4. 用实测材料批次参数做最坏情况，而非只用名义屈服强度；
5. 将材料选择写回 Forge 的设计判决和硬件四轴，未满足者为 `unknown` 或 `fail`，不得被总分掩盖。

### 4.2 不锈钢的正确位置

不锈钢可作为真空壳体、支撑、可拆卸法兰和部分结构件的候选材料，但必须逐件验证：磁导率、焊接后性能、低温韧性、疲劳、放气、氢/氚兼容性、辐照激活和热膨胀失配。

它不能自动替代线圈导体，也不能因为“强度高”就跳过 `B²R/(2μ₀t)`、脉冲载荷和电磁耦合分析。导体、结构承力件、真空边界和屏蔽材料应分层选择。

### 4.3 循环利用与报废边界

- **可重复使用**：支撑框架、接口板、诊断载台、功率电子机箱、非污染真空件、校准工装。
- **可更换后再用**：线圈模块、内衬、探针盒、密封件、热端连接件；每次拆换记录循环数和性能漂移。
- **不得默认再用**：发生辐照损伤、氚/放射性污染、不可检测裂纹、超出疲劳寿命或磁性能漂移的部件。
- 每种材料建立“拆解—检测—分流—回收”的质量门；回收质量不等于可直接回到高场关键件。

保留上游 G0–G7，但给每一门增加制造系统交付物和“可复用性”判据。时间仍按季度证据包、半年 Go/Pivot/Stop、年度独立复核。

## 6. Forge 软件系统应如何服务这份计划（不在本轮写代码）

本版只定义需求，不实施代码改动：

1. 物理源头继续由 ProjectionPhysics 提供；Forge 只记录版本、公式出处、锚点和判决结果。
2. 设计评分必须加入净空、场峰值、材料/结构门和模块拆装约束；原始 term、penalty 和判决仍全部落 registry。
3. 每个设计产生可制造 BOM、接口版本、材料批次槽位、检测计划和复用次数槽位；缺数据就输出 `unknown`。
4. 真实实验数据以独立记录类型进入 registry，不能覆盖仿真记录；仿真—现实误差单独统计。
5. 搜索报告同时展示性能、可造性、诊断可观测性、循环寿命和不确定性；禁止只按单一 score 排名。
6. 每轮制造复盘写回 wiki：保留成功工艺，也保留失败工艺、报废原因和不可复用边界。

## 7. 本版的明确否定与停止条件

- 不把“重复利用”解释成聚变装置可以无限运行；高能、中子、辐照和疲劳会产生真实寿命上限。
- 不把“一次压铸”解释成所有部件都做成整体件；对高风险边界，模块化和可检测性优先。
- 不把不锈钢解释成默认最佳材料；其适用性由磁、热、结构、真空和辐照联合门决定。
- 不把 Forge 的 `1.381419` 或 D9857 解释成聚变可行性；它只证明旧目标函数会奖励近采样点退化。
- 不把 `μ≈0.999`、`μ≈0.9997` 或 `μ=1` 当作已实现状态；它们分别是模型目标、条件估算或边界状态。
- 不在 D1 之前建大型终局装置，不在 G4 之前把 μ 当主约束，不在材料/寿命门通过前扩大产能。

## 8. 首个 90 天交付清单

1. 冻结需求树：每个物理量、制造量和诊断量都有单位、容差、来源和失败动作。
2. 复核 Forge 的净空退化：把 D9857 作为反例，定义可造性判决的最小字段集合。
3. 建立材料矩阵：不锈钢、铜/高场导体、绝缘、内衬、屏蔽分别列适用温区、载荷、检测和回收路径。
4. 画出固定层/芯盒层/场源层接口，先做单模块首件，不采购终局设备。
5. 完成 D1 零假设、误差预算和独立复核协议；把 G1 设为真正的采购闸门。
6. 为每个候选模块定义循环测试：拆装、热循环、脉冲载荷、真空保持、场漂移和报废判据。
7. 输出第一份“物理—制造—诊断”联合证据包；若 μ 没有可测签名，立即转 FRC/标准路线，不继续堆制造复杂度。

## 9. 结论

新版计划吸收的是 Musk 式的工程精髓：需求可审问、零件可删除、结构可简化、循环可加速、重复动作可自动化；但每一步都被 ProjectionPhysics 的公式、Forge 的可复现记录和独立实验判决约束。

因此路线不是“先造一台更大的聚变机器”，而是：**先造一套能低成本制造和淘汰模块的证据机器，再让物理结果决定何时放大。**
