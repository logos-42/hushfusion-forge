# 发育式持续学习（V6.1 / V7 计划）—— 模型本身的重塑

> 状态: **计划(draft)**, 未实现。V6 阶段定稿后开始。
> 性质: 这是对 `oml_continual_core.py` 的**架构级升级**, 不是加参数。

## 0. 为什么需要这一层

现状(已实测): OML 双循环 = 内循环(PLNHead 克隆参数在 support 上 Meta-SGD 适应) +
外循环(query loss 更新 meta 参数)。这是**固定两层**, 深度/宽度/交互方式在训练前就定死。
V5/V6 守护进程证实它能学会「配置→score」并显著赢 cold(Δ=+0.79, warm 100% 选 ek),
但**结构不发育**: 不会因为任务需要而长出第三层, 不会去掉没用的层, 不会在层间创造新连接。

leo 要的(原话): 「自动发育机制, 自动扩展更多层, 并在层之间交互」「收敛到真正适合任务的层级
(3/4/5 层), 或者在层级之间来回创造出属于自己的结构」「不只是内容的持续学习, 更是模型本身的重塑
—— 类似神经可塑性」。

## 1. 核心机制：三个可塑性算符

把「模型本身的重塑」实现为**离散的结构算符 + 连续的参数学习**双轨。参数学习照旧(内外循环),
结构算符是 meta 层的动作 —— 每隔 K 步评估一次「当前结构好不好」, 然后决定增/删/连。

### A. 扩展（长出层）—— 复制-变异

条件: 当前层的**隐性容量耗尽**。判据 = 该层输出的**残差持续高**:
```
residual_t = ||y_pred - y_true|| 的滑动均值
若 residual_t 连续 N 步 > 阈值 且 该层是「最忙」层 ⟹ 触发复制-变异
```
动作: 把最忙层 **一分为二**, 中间插入一个随机初始化的转换层(linear→tanh),
两个半层各自继承原层的输入/输出投影。宽度不变, 深度+1。
> 这模仿皮层发育: 区域负责的功能变多时, 原有区域分裂出功能区。

### B. 剪枝（去掉层）—— 显著性衰减

条件: 某层的**输入-输出互信息**持续低于阈值(它传导的信息 ≈ 恒等或噪声)。
判据 = 层输出与输入的互信息估计 + 该层参数在 query loss 上的梯度范数。
动作: 移除该层, 把它的前一层输出直连后一层, 重投影(保持 I/O 维度)。
> 模仿突触修剪: 不用的连接被消除, 网络更稀疏、更泛化。

### C. 交互（层间连接）—— 横向/跳跃连接

条件: layer[i] 与 layer[j] 的**表征相似度**进入一个区间(既不完全相关也不完全独立)。
判据 = CKA 相似度。相似度 > 阈值 ⟹ 合并(冗余); < 阈值且梯度相关性高 ⟹ 加跳跃连接。
动作: 在 i→j 之间插入一个可学习 gate(初始 0, 由外循环决定是否打开)。
> 模仿皮层可塑性: 同步激活的神经元建立连接(LTP), 不同步的断开。

## 2. 发育调度器（meta-controller）

上面的算符不会每步都跑 —— 那会震荡。用一个**发育控制器**决定何时评估结构:

```
每 D 步(发育周期, 如 200):
  1. 冻结参数, 在 validation 集上量每层残差/互信息/CKA
  2. 算符选择:
       - 残差高 + 容量耗尽      → 扩展(复制-变异)
       - 互信息低 + 梯度小       → 剪枝
       - CKA 区间匹配 + 梯度相关 → 加跳跃连接
  3. 执行结构变更(保留参数, 只改拓扑)
  4. 发育日志: 记录变更 + 变更后 loss, 回填「这个变更值不值」
```

**发育日志 = 结构记忆**: 每次结构变更与其导致的 val-loss 变化一起记录。
后续扩展/剪枝决策参考历史(哪种变更在这个任务上曾经有效, 哪种有害)。

## 3. 收敛判据（怎么算「发育完成」）

不预设层数。收敛 = 结构变更带来的 val-loss 改善低于阈值:
```
若连续 3 个发育周期, 扩展/剪枝/连边都没有让 val-loss 改善 > ε ⟹ 冻结结构, 进入纯参数学习
```
此时结构是**任务适合的**(可能 3 层也可能 5 层)。结构冻结后参数仍持续学习(内容持续学习不停止)。
若之后任务分布漂移(val-loss 回升), **解冻结构**, 重新允许发育 —— 这是「再次重塑」。

**v6 落地为「长层后无收益即停止」(no_gain_after_grow)**: 每次长层后重置探测器,
跟踪新结构的 val。若新结构训练了 stop_patience 个周期, val 从未低于长层前最佳
⟹ 这次长层没带来收益, **冻结结构, 停止发育**。这比「连续 N 周期无改善」更直接:
它问「长出来的层有没有用」, 没用就停。**不预设层数上限** —— 有用就继续长, 没用就停,
任务适合几层就收敛到几层。

## 4. 与现有代码的关系（不改协议, 只换内核）

- `oml_continual_core.py` 的 `OMLDesignLearner` 是**接口面**: `oml_step / predict / select_topk_*`
  保持不变 —— 守护进程 v5/v6 不感知内部结构变化。
- 新增 `scripts/develop_learner.py`: 发育控制器 + 三个算符, 包装 OMLDesignLearner。
- 新增 `scripts/oml_develop_daemon.py`: v7 守护进程 —— 配置×判据空间 + 发育调度。
- 判据不变: warm/cold 交替, warm 均值 vs cold 均值。新增判据: 发育到稳定结构后
  的 val-loss 必须 ≤ 固定两层结构(发育结构的优势必须可测)。

## 5. 深度探索 spike（已完成, 2026-10-07）—— 深度极限先钉死, 发育条件后补

leo 指示: **先把「深度探索」的极限做好, 先不要自动发育**; 发育条件等收敛时再完善。
本 spike 就在**真实 v6 经验池**(151 条 配置→score, 11 维特征)上扫深度极限,
给将来的发育机制一个「几层够用」的锚点。

**方法**: 5-fold 隔离, 隐藏层 {1,2,3,4} × 宽度 32, 普通 Adam(先测容量上限, 不混 OML)。

| 隐藏层 | val-MSE mean | 相对 1 层 |
|---|---:|---:|
| 1 | 0.0621 | — |
| 2 | **0.0614** | +1.2%(噪声内) |
| 3 | 0.0655 | −6.7% |
| 4 | 0.0710 | −8.4% |

**结论(多 seed 复核, 差异在噪声内)**:
1. **深度极限 = 1~2 层**。3/4 层退化 —— 151 条小样本撑不起深网络。
2. 现有 `PLNHead`(1 隐藏层)恰好在这个极限上, **没有亏容量** → 不需要加层。
3. **发育机制的「扩展」在这个任务上不该触发** —— 数据量是深度的上界。
4. 真正值得探索的发育维度是**宽度/特征维度**(32 宽够不够), 不是深度。

**这给 v7 的锚点**: 发育控制器先量「数据量 → 最大安全深度」, 深度 > 该值直接不触发扩展;
等任务分布变复杂/数据变多, 深度极限上移, 扩展才被允许。发育条件留待收敛期完善。

## 5b. 宽度探索 spike（已完成, 2026-10-07）—— 容量饱和点

| 宽度 | val-MSE(3 seed 中位) |
|---|---:|
| 16 | 0.0597 |
| 32 | 0.0614 |
| 64 | **0.0600** |
| 128 | 0.0591 |
| 256 | 0.0629 |

**结论**: 宽度 16~128 差异全在噪声内(±0.002), 256 略退化 —— **宽度也不是瓶颈, 数据量才是**。
两个方向(深 1~2 层 / 宽 16~128)共同指向: 151 条小数据撑不起大模型, **当前任务容量已饱和,
发育机制现在不该触发**。这是「发育锚点」的完整画像。

## 5c. 发育判据教训（2026-10-07 实测, 写死）

**「残差持续不降」是坏判据 —— 浅层永远不会满足它。**
实测: 1 隐藏层在 deep 任务上 val 轨迹 `0.2595→0.0159→0.0152` 全程每 50 轮都有微小下降
(相对改善 > 0.1%), **从未停滞** —— 但它的地板(0.0152)远高于 2 层(0.0078)。
浅层的失败是**慢性低效逼近**, 不是停滞: 它永远在慢速改善, 永远够不到深层地板。

⟹ 发育触发判据必须改成:
1. **残差下降速度**低于阈值(最近 k 周期改善 < ε, 而非「绝对不降」); 或
2. **残差 vs 理论地板**的差距: 若浅层已逼近**它自己的能力上限**但仍远离目标
   (如 val 不再随训练改善且 > 期望地板), 才该长层。

判据 2 更可靠: 它问「这个结构的能力上限够不够」, 而非「它是不是卡住了」。
这个失败模式是真实的、可复现的 —— 发育条件留待收敛期按此设计。

## 5d. 发育机制首次可工作（2026-10-07, spike v3）—— 相对衰减判据

v2 坏判据(绝对平台)在浅层永不触发(3000 轮 min EWMA 0.0093 > 1e-3, 慢性逼近)。
**v3 换成相对衰减**: 当前 EWMA 改善率 / 早期平均改善率 < 0.2 持续 3 周期 ⟹ 触发。
四场景全对: 快速下降不触发 / 慢性逼近触发(浅层能被识别) / 真平台触发 / 漂移触发。

**发育核心 spike v3 结果**(deep 任务, 3 seeds):
```
对照 2层[8]     0.014201
对照 3层[8,4]   0.008945
发育(2层起)     0.010801   n_hidden=[3,3,3] grows=[2,2,2]  ← 每个 seed 自动长层 2 次
```
- **发育版自动长层: 1 隐藏层 → 2 → 3, 6/6 次成功触发**
- 发育版 vs 固定 2 层: **改善 +23.9%**(长层有效, 不是空转)
- 发育版 vs 固定 3 层: 差 +20.8%(未达, 因触发偏晚 ep 650/1450, 第二次长层后仅剩 50 轮)

**结论**: 「模型自己决定长层」**首次可工作** —— 相对衰减判据让结构按任务需求自我调整。
剩余差距是**时机/预算调参**(更早触发、长层后给足训练), 不是机制失败。
这印证 leo 的判断: 发育条件留待收敛期完善 —— 判据已能触发, 调参等接入真实数据再做。

## 5e. 发育机制价值被证实（2026-10-07, spike v3 补跑 2000 轮）—— 自己长的结构 > 固定深层

v3 之前差 +20.8% 是因为只训 1500 轮(第二次长层后仅剩 50 轮)。**补跑 2000 轮**:

```
对照 2层[8]     0.013124
对照 3层[8,4]   0.008235
发育v3(串行)    0.006031   ← 超过固定 3 层! (改善 -27%)
发育v4(+跳跃)   0.006921   gates=[0,0] 从未打开
```

**两个结论**:
1. **发育版(自动长层)在预算充足时自己长出的结构, 比固定 3 层更好 (-27%)** ——
   「模型自己决定层数」的价值被证实: 它按需生长, 不预设结构。
2. **跳跃连接 gate 从未打开**(全 0) —— 机制存在但 deep 任务不需要跨层交互
   (纯串行组合就够了)。记录为诚实结果: 跳跃连接需要「任务真的需要跨层特征
   融合」(如多尺度)才激活, 不是万能药。

## 5f. 剪枝 spike（2026-10-07）—— 小网络无冗余可剪, 判据不可触发(诚实)

三个 spike 指向同一结论, **剪枝在小尺度自然训练的网络里没有可剪对象**:

- **v5a 梯度范数判据不触发**: 自然训练 4 层(simple 任务)每层梯度范数健康
  (0.008~0.020), 无弱层 —— 过度参数化让每层都参与分摊任务, 没有死层。
- **v5b 恒等层构造也失败**: 恒等初始化的透传层(simple 任务)梯度不小 ——
  误差信号穿过它传到前面层, 它自己也参与学习, 不是「死重」。
- **消融敏感性(逐层删除直接测)**: 3 层网络删任何一层都造成 **43~76% 退化**
  (完整 0.000791 → 删第1层 0.001130 / 删第2层 0.001396) —— **没有冗余层**。

**结论**: 「冗余层」在自然训练的小网络上不是自然出现的结构 —— 每层都有贡献,
梯度范数 / 消融敏感性都测不出死层。**剪枝判据(A/B)在此规模不可触发是物理事实,
不是 bug**。剪枝要等到**网络大到出现真正的死重**(如大模型里被湮没的层)
或**结构漂移后**(发育产生的层后来变得没用)才可能触发。诚实记录, 不做无意义的触发调参。

## 5g. 收敛判据 spike（2026-10-07, v6）—— 自我扩展 + 冷却期防误停

**v6a(无冷却期)**: 停止判据 stop_patience=3 太短, 长层后新层还没学完就被误判
「无收益」→ seed1/2 在 2 层就停, val 0.026 vs 对照 2 层 0.0115 差一倍。**教训: 
「新层还没学完的暂时持平」≠「长层无收益」, 必须给冷却期。**

**v6b(加 grow_cooldown=20, stop_patience=8)**: deep 任务 3 seeds 全部自动长层,
**发育版 0.003824 vs 固定 2 层 0.011510(改善 −67%)**, 自我扩展到 4~5 隐藏层
(每长一层 val 都降: seed0 0.0192→0.0091→0.0062→0.0051)。

```
发育+收敛(2层起)  0.003824   n_hidden=[5,4,4]
对照 2层[8]        0.011510
对照 4层[8,8,8,8]  0.001258
```

**两个结论**:
1. **发育机制自我扩展到任务所需深度(4~5 层), 且每层都带来收益** —— 「收敛到
   真正适合任务的层级」的正面证据: 不预设层数, 任务需要几层就长到几层。
2. **停止判据未触发(epochs_exhausted)是任务性质, 不是 bug**: deep 任务长层
   持续有收益, 3000 轮内没出现「新层无收益」的时刻。冷却期已修好 v6a 的误停,
   停止判据在「长层没收益」的任务上才会触发(与剪枝区同场景)。

## 6. 诚实边界

- **结构搜索是昂贵的**: 发育周期要冻结参数评估, 比纯参数学习慢。效费比要实测。
- **结构 vs 参数是旧的 bias-variance 权衡**: 扩展不一定赢 —— 有时候任务就是 2 层够。
  所以收敛判据不预设层数, 让数据说话。
- **发育日志的好坏回填是 meta 学习**: 会 suffering from "learning to learn" 的数据饥渴,
  早期发育决策可能震荡。要给它足够的发育周期才下结论。
- **不承诺「3 层一定比 2 层好」**: 承诺的是「结构能按任务需求自我调整, 且调整有据可查」。
- 本计划不动物理判据(forge 的分数/门), 纯是持续学习内核的结构升级。

## 7. 落地顺序

1. **spike**: 最小发育实验(本计划 §5) —— 证「残差→扩展」成立。≤1 天。
2. **发育调度器 + 日志**: 独立模块, 不碰 OMLDesignLearner 接口。≤2 天。
3. **剪枝 + 连边**: 三个算符齐。≤2 天。
4. **v7 守护进程**: 远端 A100 长跑, warm/cold + 发育结构对比固定两层。≤1 天。
5. 回写 wiki + 提交。

## 8. 一句话

**V6.1/7 = 让模型自己决定自己长几层、连哪几层、去掉哪层 —— 结构像内容一样可被持续学习重塑。**
