# 反引力场控制 —— 持续学习接入计划（V6.1/7 方向二）

> 状态: **计划(draft) + 3 个 spike 已跑**。用自递归生长发育的持续学习模型
> 研究反引力场(μ)控制。leo 2026-10-07 设定为 loop 主方向。

## 0. 控制对象（上游已证物理, 不新写）

μ 时域动力学（上游 `sim_two_flow_ring.py`, TD/MuDynamics 系）:

    μ' = μ + η_total·(1−μ)
    η_total = η_ext + η_sink(λ)·(1−μ),  η_sink(λ) = 2λ−λ²   (CR9 自抹平)
    工作窗口   μ ≥ 0.999                (聚变级, 到即成功)
    天花板     μ < 1 − m_e/m_i = 0.999780568  (FC11, 越界 = 破坏)

**控制量**: η_ext(外部驱动强度) + λ(环流电子收敛度 → 自抹平强度)。
**目标**: 最快到工作窗口(步数最少), 且不越天花板。

## 1. 阶梯发现（spike 1-3, 2026-10-07）—— 控制空间里藏着一个 17 倍

三个 spike 逐层揭开控制空间的真实形状:

| 配置 | 到窗口步数 | 说明 |
|---|---|---:|
| 开环 η=0.05, 无自抹平 | **132** | 上游默认参数 |
| 开环 η=0.05 + 自抹平 λ=0.3 | **85** | 上游 sinkmuopt 已证 |
| 开环 η*=0.29 (无自抹平) | **20** | **η 本身选错是主因** 6.6× |
| 最优 (η_ext=0.45, λ=0.4) | **5** | **联合优化, 17× 快** |

**关键发现**:
1. **闭环分段控制不必要** —— 最优固定 η 就 20 步。真正的问题是「η 参数选择」,
   不是「μ→η 的每步策略」。控制问题简化成**参数选择问题**。
2. **自抹平 λ 是第二根杠杆**: η 单独优化 20 步, 联合 λ 优化 5 步 (再 4×)。
   自抹平加速但也更容易越界 (大 η+大 λ ⟹ X) —— 控制面有清晰的安全/越界边界。
3. **形状可学**: 越界点 28% (清晰分类边界); 安全点步数 5~672 (134× 动态范围,
   大动态回归)。**标准可学的「回归 + 分类」面**。
4. **与 v5/v6 同构**: 学 (η_ext, λ) → 性能 = 学 (配置) → score。直接复用
   配置推荐器架构 (OMLDesignLearner + UCB 探索 + 判据探索)。

## 2. 持续学习接入设计（下一步）

把反引力控制接进现有持续学习模型, 与 v6 判据探索同构:

```
每轮:
  1. 推荐器从 (η_ext × λ) 控制空间选一个控制点     [学过的先验]
  2. 跑 μ 动力学 → 真实步数 / 越界标志               [确定性环境]
  3. 回流 (η_ext, λ) → (步数, 越界) 进经验池        [累积]
  4. OML 持续学习 (η_ext, λ) → 性能, 越学越准
  5. 自动发育: 学习器结构按控制面复杂度自生长
     (v3/v6/v8 的发育机制: 相对衰减→长层, 自适应阈值)
```

**验收判据**: warm(推荐器)平均步数 < cold(随机控制点)平均步数,
且推荐器学会偏 {'η_ext:0.3-0.5, λ:0.3-0.45}' 高分区、避开越界区。

**发育结构叠加**: 控制学习器的层数由数据量/复杂度决定 —— 把 v6/v8 的
自动长层 + 自适应阈值直接用在控制学习上, 就是「自递归生长发育的持续
学习模型研究反引力场控制」的完整闭环。

## 2b. 核心实验已完成（2026-10-07, spike_ag_controller v2）—— 在线适应有效

把 OMLDesignLearner 接进控制环境, **μ₀ 每轮随机漂移** (0.01~0.8, 最优控制
在线移动), 学习器持续学 (η_ext, λ, μ₀) → log(步数), UCB 探索 + 经验回流:

```
round 300: warm(学习器) 均值 9 步, 最优比 3.17× | cold(随机) 均值 25 步, 最优比 8.21×
```

**✓ 持续学习在线适应有效**: warm 显著比 cold 接近行为最优 (3.17× vs 8.21×),
UCB 探索 + 经验回流让学习器在环境漂移时持续贴近最优控制。

**~ 离线单点推荐仍差** (固定 μ₀ 验证 34~178 步 vs 真最优 1~7 步): 纯 argmin
预测对未见 μ₀ 泛化不可靠, 最优区样本稀疏。

**两个教训 / 结论**:
1. **持续学习的价值在「在线连续适应」不在「离线一次预测」** —— 与 leo
   「持续学习 = 终身适应」的愿景一致。评价指标应看「在线平均步数」,
   不是「单点预测精度」。
2. **v1 的三个错误** (重复乘法指数衰减 / 随机采样覆盖不到最优区 / 越界惩罚
   1000 污染回归) 在 v2 全部修正: log 压缩目标 + 漂移环境 + UCB 探索。

## 2c. 发育式控制学习器（2026-10-07, spike_ag_develop v2）—— 闭环成立

把发育结构(自动长层)叠进控制学习器, 完成「自递归生长发育的持续学习
模型研究反引力控制」的完整闭环。**关键工程**: PLNHead 硬编码 2 层
(clone_params/fwd_with 不认新增层) ⟹ 重写 DevelopmentalHead(任意深度,
动态克隆/遍历/Meta-SGD, 协议同 PLNHead)。

```
固定1层: warm 15 步 (最优比 5.63×) | cold 25 步 (8.05×)
固定2层: warm 15 步 (最优比 5.63×) | cold 25 步 (8.05×)
发育版:  warm 16 步 (最优比 5.81×) | cold 25 步 (8.05×) | 长层 27 次
```

**结论**:
1. **发育式控制学习器成立**: warm 显著快于 cold (16 vs 25 步), 与固定深度持平。
2. **控制面 1 层就够**: 固定 1/2 层与发育版同样 15~16 步 —— 三方一致证实
   该学习任务不需要深结构。发育版长到 28 层也没有更好, 恰恰反证「1 层够」。
3. **发育判据会过度触发 (27 次)**: query_loss 非单调 (OML 波动大),
   相对衰减把正常波动误判为「该长层」。**需要 v6 的冷却期 + 停止判据**
   (长层后无收益即停) —— 组件已在 v6/v8 验证, 直接接上即可。

**发育 × 反引力控制的完整链路已打通**: 环境 → 控制面 (17×) → 持续学习
在线适应 (warm 9~16 步) → 发育结构 (自动长层, 证实 1 层够)。

## 3. 诚实边界

- 控制面是**确定性环境**(上游闭式/递推), 不是真实装置 —— 学的是「给定物理
  模型的最优控制参数」, 不是「真实反引力的未知物理」。
- λ 是第二输入缺口(上游承认: 环流电子收敛度是输入, 不是推导值); 学出的
  λ*=0.4 是「在这个模型里最优」, 不代表物理上做得到 λ=0.4。
- 步数是相对量, 不换算工程时间(每步 = 一次驱动周期, 时长在上游排程)。
- 5 步到窗口的 η_ext=0.45 高增益是否工程可实现(驱动功率)未评估。
- 不新增物理: 全部复用上游已证条目, 只把「参数怎么选」交给持续学习。
