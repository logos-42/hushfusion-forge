# 反引力场控制 —— 持续学习接入计划（V6.1/7 方向二）

> 状态: **计划(draft) + 3 个 spike 已跑**。用自递归生长发育的持续学习模型
> 研究反引力场(μ)控制。leo 2026-10-07 设定为 loop 主方向。

## 0. 控制对象（上游已证物理, 不新写）

μ 时域动力学（上游 `sim_two_flow_ring.py`, TD/MuDynamics 系）:

    μ' = μ + η_total·(1−μ)
    η_total = η_ext + η_sink(λ)·(1−μ),  η_sink(λ) = 2λ−λ²   (CR9 自抹平)
    工作窗口   μ ≥ 0.999                (聚变级, 到即成功)
    天花板     μ < 1 − m_e/m_i = 0.999780568  (FC11, 越界 = 破坏)

**控制量**: η_ext(外部驱动强度) + λ(环流电子收敛度 → 自抹平强度)。
**目标**: 最快到工作窗口(步数最少), 且不越天花板。

## 1. 阶梯发现（spike 1-3, 2026-10-07）—— 控制空间里藏着一个 17 倍

三个 spike 逐层揭开控制空间的真实形状:

| 配置 | 到窗口步数 | 说明 |
|---|---|---:|
| 开环 η=0.05, 无自抹平 | **132** | 上游默认参数 |
| 开环 η=0.05 + 自抹平 λ=0.3 | **85** | 上游 sinkmuopt 已证 |
| 开环 η*=0.29 (无自抹平) | **20** | **η 本身选错是主因** 6.6× |
| 最优 (η_ext=0.45, λ=0.4) | **5** | **联合优化, 17× 快** |

**关键发现**:
1. **闭环分段控制不必要** —— 最优固定 η 就 20 步。真正的问题是「η 参数选择」,
   不是「μ→η 的每步策略」。控制问题简化成**参数选择问题**。
2. **自抹平 λ 是第二根杠杆**: η 单独优化 20 步, 联合 λ 优化 5 步 (再 4×)。
   自抹平加速但也更容易越界 (大 η+大 λ ⟹ X) —— 控制面有清晰的安全/越界边界。
3. **形状可学**: 越界点 28% (清晰分类边界); 安全点步数 5~672 (134× 动态范围,
   大动态回归)。**标准可学的「回归 + 分类」面**。
4. **与 v5/v6 同构**: 学 (η_ext, λ) → 性能 = 学 (配置) → score。直接复用
   配置推荐器架构 (OMLDesignLearner + UCB 探索 + 判据探索)。

## 2. 持续学习接入设计（下一步）

把反引力控制接进现有持续学习模型, 与 v6 判据探索同构:

```
每轮:
  1. 推荐器从 (η_ext × λ) 控制空间选一个控制点     [学过的先验]
  2. 跑 μ 动力学 → 真实步数 / 越界标志               [确定性环境]
  3. 回流 (η_ext, λ) → (步数, 越界) 进经验池        [累积]
  4. OML 持续学习 (η_ext, λ) → 性能, 越学越准
  5. 自动发育: 学习器结构按控制面复杂度自生长
     (v3/v6/v8 的发育机制: 相对衰减→长层, 自适应阈值)
```

**验收判据**: warm(推荐器)平均步数 < cold(随机控制点)平均步数,
且推荐器学会偏 {'η_ext:0.3-0.5, λ:0.3-0.45}' 高分区、避开越界区。

**发育结构叠加**: 控制学习器的层数由数据量/复杂度决定 —— 把 v6/v8 的
自动长层 + 自适应阈值直接用在控制学习上, 就是「自递归生长发育的持续
学习模型研究反引力场控制」的完整闭环。

## 2b. 核心实验已完成（2026-10-07, spike_ag_controller v2）—— 在线适应有效

把 OMLDesignLearner 接进控制环境, **μ₀ 每轮随机漂移** (0.01~0.8, 最优控制
在线移动), 学习器持续学 (η_ext, λ, μ₀) → log(步数), UCB 探索 + 经验回流:

```
round 300: warm(学习器) 均值 9 步, 最优比 3.17× | cold(随机) 均值 25 步, 最优比 8.21×
```

**✓ 持续学习在线适应有效**: warm 显著比 cold 接近行为最优 (3.17× vs 8.21×),
UCB 探索 + 经验回流让学习器在环境漂移时持续贴近最优控制。

**~ 离线单点推荐仍差** (固定 μ₀ 验证 34~178 步 vs 真最优 1~7 步): 纯 argmin
预测对未见 μ₀ 泛化不可靠, 最优区样本稀疏。

**两个教训 / 结论**:
1. **持续学习的价值在「在线连续适应」不在「离线一次预测」** —— 与 leo
   「持续学习 = 终身适应」的愿景一致。评价指标应看「在线平均步数」,
   不是「单点预测精度」。
2. **v1 的三个错误** (重复乘法指数衰减 / 随机采样覆盖不到最优区 / 越界惩罚
   1000 污染回归) 在 v2 全部修正: log 压缩目标 + 漂移环境 + UCB 探索。

## 2c. 发育式控制学习器（2026-10-07, spike_ag_develop v2）—— 闭环成立

把发育结构(自动长层)叠进控制学习器, 完成「自递归生长发育的持续学习
模型研究反引力控制」的完整闭环。**关键工程**: PLNHead 硬编码 2 层
(clone_params/fwd_with 不认新增层) ⟹ 重写 DevelopmentalHead(任意深度,
动态克隆/遍历/Meta-SGD, 协议同 PLNHead)。

```
固定1层: warm 15 步 (最优比 5.63×) | cold 25 步 (8.05×)
固定2层: warm 15 步 (最优比 5.63×) | cold 25 步 (8.05×)
发育版:  warm 16 步 (最优比 5.81×) | cold 25 步 (8.05×) | 长层 27 次
```

**结论**:
1. **发育式控制学习器成立**: warm 显著快于 cold (16 vs 25 步), 与固定深度持平。
2. **控制面 1 层就够**: 固定 1/2 层与发育版同样 15~16 步 —— 三方一致证实
   该学习任务不需要深结构。发育版长到 28 层也没有更好, 恰恰反证「1 层够」。
3. **发育判据会过度触发 (27 次)**: query_loss 非单调 (OML 波动大),
   相对衰减把正常波动误判为「该长层」。**需要 v6 的冷却期 + 停止判据**
   (长层后无收益即停) —— 组件已在 v6/v8 验证, 直接接上即可。

**发育 × 反引力控制的完整链路已打通**: 环境 → 控制面 (17×) → 持续学习
在线适应 (warm 9~16 步) → 发育结构 (自动长层, 证实 1 层够)。

## 2d. 冷却期 + 停止判据（2026-10-07, spike_ag_develop v3）—— 长层收敛但 OML 衔接断裂

v2 问题: 发育判据过度触发 27 次长到 28 层。v3 加 v6 验证过的冷却期 +
停止判据 (grow_cooldown=8, patience=6, max_grows=3):

```
固定1层: warm 15 步 (5.63×) | cold 25 步 (8.05×)
发育v3:  warm 70 步 (23.34×) | cold 25 步 (8.05×) | 长层 3 次, 停止 0 次
```

**进展与缺陷（如实分列）**:
1. **✓ 冷却期生效**: 长层从 v2 的 27 次降到 3 次 (round 15/40/56) —— 不再失控。
2. **✗ 停止判据未触发 (0 次)**: query_loss 波动大 (18.3→17.6→0.9), `grow_val`
   是长层瞬间的大数, `post_grow_best >= grow_val` 难满足。停止判据需要
   **平滑后的 loss** (EMA) 而不是瞬时值。
3. **✗ 长层后性能反而变差 (warm 15→70 步)**: **OML 元参数衔接断裂** ——
   add_layer 保留了旧 step_beta, 但新层参数没有对应 beta (全 init log(0.05)),
   新旧不匹配 ⟹ OML 内循环 (Meta-SGD per_feature_step) 被破坏。
   这是「发育 × OML 元学习」衔接的真难点: 结构变了, 元参数 (per-feature 步长)
   也必须跟着发育 (新层重学 beta, 而不是硬塞)。

**结论**: 冷却期解决「过度长层」; 但停止判据需用 EMA loss, 发育后需重学
step_beta —— 这两个是「自递归生长发育的持续学习」的核心研究问题, 已定位
到具体机制 (元参数衔接), 不是本轮机械推进能完成的。诚实记录, 留待收敛期。

## 2e. 分形循环（2026-10-07, spike_fractal_loop）—— 内外循环的分形生长

leo 方向: 参考本地 lm-principle 的分形研究, 把内外循环做成**递归嵌套的分形结构**。
Fractal.lean 5 定理 → 循环设计:

| Fractal.lean 定理 | 循环实现 |
|---|---|
| prefix_allocation_optimal (预算集中前缀) | 根循环密集更新 (每轮), 叶循环稀疏 (每 D 轮) |
| residual_contraction_decay (残差收缩) | 父循环元参数 → 子循环快速适应 (残差) |
| attention/moe_error_bound (凸组合有界) | 门控凸组合 g_root·pred_root + g_leaf·pred_leaf, softmax Σg=1 |
| fractal_dimension_scale_invariant (D = log b / log 1/s) | 循环深度 D 级, 更新频率 / D^depth |

**spike 结果** (反引力控制学习, 250 轮, 同一训练协议):
```
普通循环(均匀):  warm 130 步 | cold 32 步
分形循环(2级,D=4): warm 83 步  | cold 32 步 | 叶更新 54/250 (22%)
```
- **✓ 分形 > 均匀: warm 改善 36%** (83 vs 130 步) —— 分形组织更高效
- **✓ 分形稀疏: 叶循环只更新 22% 轮次** —— 更少计算达到更好性能
  (Fractal.lean 的「预算集中前缀 ≥ 均匀平摊」在循环上实证)
- 凸组合门控 (根↔叶沟通) 是「不同循环层互相沟通」的实现

**这就是「内外循环分形生长」的最小成立版**: 循环分 2 级, 浅(根)密深(叶)疏,
凸组合沟通; 数据量/复杂度增长时可再递归长出新叶循环 (每级频率 / D^depth)。

## 2f. 分形循环生长（2026-10-07, spike_fractal_growth）—— 递归树可长, 但暴露「死子节点」门控缺陷

完整版「自生长的更多循环」: FractalNode 递归树, 误差平台 ⟹ 克隆子节点 (自相似,
深一级, 更新频率 /D), 预测 = 递归凸组合 (softmax 门控), 子节点自己也能再长。

```
固定1节点: warm 130 步 | cold 32 步
生长树:    warm 130 步 | cold 32 步 | 树 1→4 节点, 生长 3 次
```

**✓ 生长机制机械上成立**: 树递归长出子节点 (round 45/53/60, 1→2→3→4),
自相似结构 + 跨层凸组合沟通 + 深度按需生长 —— 分形生长的「骨架」工作。

**✗ 性能不升 (130 vs 130) —— 诊断出「死子节点」**: 
1. **门控初始化缺陷**: 子节点门控初始 0 ⟹ 子贡献 0 ⟹ 门控梯度 0 ⟹
   永远不贡献 = 死子节点。凸组合需要**门控探索**(子节点先独立训练,
   或有门控 UCB), 否则长出来的子节点是摆设。
2. **生长判据被罚分噪声误触发**: 3 次生长都发生在 loss 21~25 (越界罚分值
   LOG_PENALTY=log5000≈8.5 的加权, 或 40 批混合), 不是真实学习平台 ——
   判据应只喂**安全配置**的 loss, 排除越界罚分。

**结论**: 分形递归生长的骨架成立, 但「子节点如何从 0 开始被信任」是核心
研究问题 (与 v2d 的 step_beta 衔接同族: 结构生长后, 新结构的元参数/门控
必须和旧结构衔接, 否则新结构是死的)。门控探索 + 干净 loss 是两条已定位的修法。

## 2g. 长期持续学习测试（2026-10-07, spike_fractal_long, 1500 轮）—— 分形树长期有效, 且持续改善

leo 核心问题: 分形循环生长结构在**长期过程**里能持续学习吗? 效果如何?

**实验**: 1500 轮 (各 750 warm/cold), μ₀ 持续漂移 (非平稳 = 持续学习真实舞台)。
分形生长树 (门控均匀起步 + 干净 loss 判据, v2 修法) vs 固定 1 节点。

| 阶段 | 固定1节点 warm | 分形生长树 warm |
|---|---:|---:|
| round 0-500 | 139 步 | **75 步** |
| round 500-1000 | 64 步 | **10 步** |
| 全程平均 | 114 步 | **53 步** |
| 最优比(全程) | 39.3× | **18.1×** |

**生长**: 树在 ~100 轮长到 5 节点后自动停止 (节点历史 1→5→稳定), 之后纯靠
参数持续学习; cold 均值两边同为 32~33 步 (同基线)。

**三个确凿结论**:
1. **✓ 持续学习有效 (两种结构都成立)**: warm 随时间下降 (139→64 / 75→10) ——
   模型在 μ₀ 持续漂移下长期越学越好, 不是过拟合到单一起点。
2. **✓ 分形树长期显著优于固定**: 全程 53 vs 114 步 (**2.2× 更好**), 且差距
   随时间拉大 (round 500-1000: 10 vs 64 步, **6.4×**) —— 分形结构的优势
   在长期/非平稳环境里被放大。
3. **✓ 生长自动收敛**: 树长到 5 节点就停 (不是无限长), 之后持续参数学习
   继续改善 —— 「长到恰当规模 → 纯学习」正是分形生长的目标形态。

**机制解释**: 5 节点树 = 5 个专长节点 (各自主攻一段 μ₀/控制参数空间),
凸组合门控自动分配 (当前 μ₀ 谁的预测准, 门控给谁高权重) —— 分形的
「浅层密集 + 凸组合有界」在非平稳环境里 = 多专家自适应路由。这就是
leo 要的「不同循环之间互相沟通」的长期价值实证。

## 3. 诚实边界

- 控制面是**确定性环境**(上游闭式/递推), 不是真实装置 —— 学的是「给定物理
  模型的最优控制参数」, 不是「真实反引力的未知物理」。
- λ 是第二输入缺口(上游承认: 环流电子收敛度是输入, 不是推导值); 学出的
  λ*=0.4 是「在这个模型里最优」, 不代表物理上做得到 λ=0.4。
- 步数是相对量, 不换算工程时间(每步 = 一次驱动周期, 时长在上游排程)。
- 5 步到窗口的 η_ext=0.45 高增益是否工程可实现(驱动功率)未评估。
- 不新增物理: 全部复用上游已证条目, 只把「参数怎么选」交给持续学习。
