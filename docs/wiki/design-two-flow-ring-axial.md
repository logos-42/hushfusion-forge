# 轴向分离双流环设计层（中性面悬空）

上游出处：`logos-42/Hibs-Physics`（本地工作副本 `~/Downloads/lean/ProjectionPhysics`）的
`docs/wiki/design-two-flow-ring.md`（可行域 + 共面版仿真）与 `docs/wiki/design-two-flow-ring-axial.md`（目标页）。
本页把上游的三步（**零场面 / 装置包络 / 有限截面修正**）收成本仓**可引用、带证据、可回归**的一页。

**这一页与量产闭环的关系**：本仓的 `clearance` 罚项与 G23 可造性门要求「导体面到中心元胞的净空 ≥ 0.05 m」——
本页给的是**同一个几何量在真正产生场反位形的位形下的取值**（中性面到导体表面的净空），
以及**导体几何必须满足的位置关系**。两处口径不同（前者是导体到**元胞**，本页是中性面到**导体表面**），
不可互相冒充；能对上的是量级与来源。

## 1. 从「共面不行」到「分开多少才行」

共面双流环的结论（上游 `cb544d8`）：**中性面贴在导体上**（单环的共面轴向场跨过自身导线就变号，
变号点恰落在内环半径 0.35 m）⟹ 不是真场反位形。

把「**让中性面悬空**」当目标，两环沿轴分置 z = ∓d/2、要求**原点为零场**：

```text
f(a,d) := a² / (a² + (d/2)²)^{3/2}          （点丝口径）
f(R_Cu, d) = λ · f(R_H, d)                  λ := |I_H| / |I_Cu|
```

两个极限都咬住既有结论（自洽性，不是巧合）：

| 极限 | λ | 意义 |
|---|---|---|
| d → 0 | R_H/R_Cu = **0.583333333** | 共面判据是本判据的**特例**（数值逐位一致） |
| d → ∞ | (R_Cu/R_H)² = **2.938775** | **分离距离有上限**：λ ≥ 2.94 时原点永远不是零点 |

⟹ **d 与 λ 一对一锁定**，装置自由参数从两个降成**一个**。

## 2. 三步的实测结论

### ③ 有限截面修正（把点丝换成真导体）

环截面 (半宽 径向 0.03 m × 轴向 0.03 m，**口径**)、截面内均匀电流：

```text
F(a,d) = ∬ a'² / (a'² + (d/2 + z')²)^{3/2}  dz' da' / 面积        λ(d) = F_Cu(d) / F_H(d)
```

| 量 | 值 |
|---|---|
| d\*（点丝口径，λ=1.5） | 1.090526 m |
| d\*（有限截面，λ=1.5） | **1.092326 m** |
| 差值 | **+0.0018 m（+0.17%）** |
| 同一 d 下两口径的 λ 差 | 1.500000（点丝）vs 1.498105（截面）= **0.13%** |

⟹ 截面把近场抹平的方向使所需 λ 略降 / 所需分离距离略增，**修正量 0.17% 量级 ⟹ 点丝口径在本截面尺寸下够用**。
这是「点丝判据能当工程判据用」的定量依据，也给出了它失效的尺度（截面尺寸 ∼ d 时修正不可忽略）。

### ① 零场面（B_z = 0 的曲面）

在 (r,z) 半平面上解 `B_z(r,z) = 0`，绕轴旋转即场反位形边界。**必须分两类**（与共面轮同一教训）：

| 类 | 点数 | 含义 |
|---|---|---|
| **干净分支**（过原点） | 470 | 真正的场反位形边界 |
| **导体邻近**（到导体面 < 2·截面半宽） | 70 | 单环近场伪影，**不是**物理零点 |

- 干净分支轴向跨度 z ∈ [−1.202, **+1.600**] m ⟹ **两端接入导体**：反向区在轴端由导体封闭，
  不是自由空间里闭合的曲面（这是结论，不是失败）。
- 干净分支到导体**表面**最小净空 = **0.0623 m**（到中心线 0.0945 m）⟹ 有真实缝隙。
- 原点 B_z = 5.4e-10（单位电流口径）⟹ 按 λ(d) 构造的零点成立。
- 轴上不对称（−1.202 vs +1.600）来自两环半径不同 ⟹ 零点面对轴**不对称**，这会影响端部设计。

### ② 装置包络与四条硬界

包络由几何给出（两环 + 环轴向半宽 + 端部余量 0.30 m；径向 = 外环外缘 + 0.20 m，均为**口径**）：

| 量 | 值 | 撞的界 | 结论 |
|---|---|---|---|
| 轴向包络 | 1.452 m | ≤ 装置尺度 L = 1.460 m | 装得下 ✓ |
| 工作场强 B | 5.88 T | < FC12 上界 6.686 T | ✓ |
| R_Cu + 截面 | 0.630 m | ≤ PF7 允许半径 1.817 m；≤ L/κ = 0.730 m | ✓ |
| 环厚 t | 0.10 m | < t_max 0.202 m | ✓ |

**与共面版可比**：L = 1.460 m / B = 5.88 T，对照共面版曾用 L = 1.4 m / B = 6.0 T
⟹ 轴向分离**不是靠放大装置**换来的（这是「值不值得做」的判据）。

## 3. 死法（写死，可判）

| 死法 | 判据 | 现状 |
|---|---|---|
| λ 出窗口 | λ ∉ [0.58333, 2.93878) | 数值已验（单调、趋向极限） |
| **λ 漂移** | d 固定时原点场残差随 ‖Δλ/λ‖ **线性**增长；残差 < 1% 需 ‖Δλ/λ‖ < 5% | 斜率恒 0.405，已验 |
| 截面修正失效 | 环截面尺寸 ∼ d 时点丝判据不可用 | 当前 0.17% ⟹ 未触发；触发尺度未算 |
| 零点面接导体 | 干净分支两端接导体 ⟹ 反向区不自由闭合 | **已实测**（不是失败，是形状） |

## 4. 诚实边界

- **口径**：截面半宽 0.03 m、环厚 0.10 m、端部/径向余量（0.30 / 0.20 m）都是**工程口径**，非上游物理结果；
  净空与包络随这些口径线性变。改动前请一并改本页与 `runs/twoflowring_axial/report.json` 的口径字段。
- **这是细丝/标准电磁学口径**：场用 Biot–Savart（结构对应层）。上游框架要求的线性叠加（PA3）与反向抵消（DR2b）已验，
  本页沿用同一场模型；**不含** μ 的主动产生（上游仍未决的输入缺口）。
- **无新物理预言**：本页是**装置几何与判据**，不是对上游物理的新预言。
- **零点面只算了轴对称半平面**；三维全场（96³）未在 GPU 上跑（本页结论不依赖它，轴上点已与解析一致 1.27e-14）。
- **未接进任何世界**：本页不进 `rlenv` / 世界协议（进动力学需新增物理，协议明文禁止）；它目前只是设计与验收依据。
- **上游数字进源码 = 违规**：本页的数**不**进 `internal/`；要变成门需按 `docs/design-layer.md` 的流程
  （先冻契约 → 编译期签名锁 → 锚点由 `scripts/emit_pp_anchors.py` 重发）。
