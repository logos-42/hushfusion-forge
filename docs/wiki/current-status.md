## 一句话状态

Phase 0 的验收问题——**"机器能不能找到一个比人工基线更好的电磁设计，而且这条结论能被独立复现"**——

## 诚实边界（必须与上面的数字一起读）

1. **最优解很可能是不可造的位形。** D9857 把一圈 `a=0.10 m`、`1.78 MA` 的线圈放在距中场采样点
   **4.196 mm** 处——落在求解器 5 mm 的 `alpha2` 钳位半径内。目标函数目前**没有"导体到约束区域的净空"约束**，
   所以它合法地把导体贴到打分点旁边换场强。任何引用 `1.381419` 的场合都必须带这句限定。
2. **热启动的增益在 1000 次预算下不显著**（1.3073 vs 1.3033，后者方差还更小）。
   "继承设计知识值多少钱"在 Phase 0 的答案是：**这个预算下 ≈ 0**。
3. **人工基线在这个盒子里是弱基线**：随机搜索平均 8 次评估就追平它。它赢在"是个真装置"，不赢在指标。
4. 真空静磁模型：没有等离子体、没有平衡、没有有限 β、没有涡流。它回答"这个线圈配置的场结构好不好"，
   **不回答**"这台装置能不能聚变"。
5. `sign_agreement` 恒为 1.000 是**复制证据不是质量分**——规则是由"每个 run 同号"硬过滤出来的，
   该字段存在的意义只是核对过滤没被绕过。
