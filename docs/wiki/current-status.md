1. **最优解很可能是不可造的位形。** D9857 把一圈 `a=0.10 m`、`1.78 MA` 的线圈放在距中场采样点
   **4.196 mm** 处——落在求解器 5 mm 的 `alpha2` 钳位半径内。目标函数目前**没有"导体到约束区域的净空"约束**，

   "继承设计知识值多少钱"在 Phase 0 的答案是：**这个预算下 ≈ 0**。
3. **人工基线在这个盒子里是弱基线**：随机搜索平均 8 次评估就追平它。它赢在"是个真装置"，不赢在指标。
4. 真空静磁模型：没有等离子体、没有平衡、没有有限 β、没有涡流。它回答"这个线圈配置的场结构好不好"，

5. `sign_agreement` 恒为 1.000 是**复制证据不是质量分**——规则是由"每个 run 同号"硬过滤出来的，

**缺陷**：0.1.2 重录 v1 黄金 trace 时漏了 `--protocol 1`（缺省 = 2）⟹ 那份文件装着 v1 的**请求序列**、
响应却是 **protocol 2** 的会话。**G18 当时是绿的 —— 假绿**：回放以 trace 自己的 `hello.protocol` 为准，
**标错版本的 trace 在回放时自己跟自己比**，必然逐字节一致。抓到它的是 `internal/world` 的单测
（`TestTraceProtocolReadsTheHelloResponse` / `TestV1GoldenTraceIsRefusedByAV2World`），
而它是由**最终全门 G5** 暴露的。

> **规则（写死）**：回放类门的判据若是「与 trace 一致」，它**无法**发现「trace 本身标错」。
> 一份证据至少要有一条**不依赖它自己**的检查。两条路都要求「对得上」，但对的东西不同：
> **一条对字节，一条对语义。**
> **发版清单新增**：重录 trace 必须**显式给 `--protocol`**。

**已修**：按显式 protocol 重录三份 —— v1 **8 请求 / 3635 字节**、v2 **10 / 7199**、mu **17 / 10048**，
Go 与 Python 客户端各逐字节复现 PASS，`internal/world` 单测 ok，全量单测全绿。

**版本税第二笔（实测）**：0.1.2 → 0.1.3 后三份 trace **再次全部失效**，成因与 0.1.2 时完全相同 ——
世界 hello 的声明里带 **engine 版本串**，而它是冻结字节的一部分。两份世界结构证据同步重测

## 判据变更 v0.1.2（2026-10-02）：可造性进目标函数

0.1.0 的最优解踩在一个**不可造的退化解**上（一圈 `a=0.10 m`、`1.78 MA` 的导体距中场采样点
**4.196 mm**），而旧目标函数没有任何一项阻止它。0.1.2 把它变成判据（契约：[../version-0.1.2.md](../version-0.1.2.md)）：

- 新增第 4 条罚项 `clearance` = `max(0, (min_clearance − min_clearance_m)/min_clearance)`；
  `spec.min_clearance = 0.05 m`（**工程判断，非物理**；硬约束 = 人工基线必须仍然可行）；
  `physics.Metrics` 新增 `min_clearance_m`（**冻结类型变更**）。
  净空口径：导体面（丝环 ± `t_pack/2`）到**中心元胞** `{0 ≤ r ≤ RPlasma, |z| ≤ ZCell}` 的距离，**可负**。

| | v0.1.0（`runs/phase0`） | v0.1.2（`runs/phase1`） |
|---|---:|---:|
| 人工基线 | −0.2905708161 | −0.2905708161（**不变**） |
| 机器最优 | 1.3814186（D9857） | **0.9488837**（D7996） |
| **Δ vs 人类** | **+1.672** | **+1.2395** |
| 可行记录 | 11072 / 12001 | **7221 / 12001** |

**「可造性这条约束值多少钱」= 0.4325（Δ 掉了 26%），同时砍掉约 32% 的搜索空间。**

**必须与上面的数字一起读的三条**：

1. 那个数字是被 `MinClearance = 0.05` 这个**工程判断**撑着的 —— 换一个值它就是另一个数，**不是物理常数**。
2. 新最优点的净空是 **0.0518751 m**（要求 0.05）——它**贴着新约束的边界**。这与 0.1.0 的边界性质不同：
   0.1.0 顶的是求解器 5 mm 的 `alpha2` **数值钳位**（物理上不存在），0.1.2 顶的是一条**声明的工程要求**。
3. 这条约束是**几何净空**，不是工程可行性审查（没算支撑结构、冷质量、装配公差、失超保护）。

**版本与发版模型（0.1.2 新增）**：版本语义写死在 [../version-0.1.2.md](../version-0.1.2.md) §3
（PATCH = 改判据本身）；`config.ForgeVersion` 是唯一真源；`runs/<tag>/results.json` 的 `meta.forge_version`
记住产出它的判据版本；G12/G15/G16 因此多了一条前置条件 —— **判据版本不匹配就 SKIP 并大声说明**
（**SKIP ≠ 通过**），因为拿新尺子量旧证据是**用错了尺子**。`runs/phase0/` 是 0.1.0 判据下的证据，
**永不重跑覆盖**。

**判据一变就必须重测的三处既有证据**：

  1e-15 量级的浮点噪声与 `runtime_seconds` ⟹ **可造性罚项不改变 v2 世界的顺序结构**
  （它不经「源 / 前提门」那条路进动力学）—— 这正是下一版 B 项要修的东西。
- G17 上游锚点：**重发**（上游今天推进到标度缺口定位页）。逐字段 diff 确认**只有 provenance 变**

## 接上游设计：双流环产生的**引力场**（目标校正，2026-10-02）

页：`docs/wiki/design-two-flow-ring-gravity.md`；证据：`runs/twoflowring_gravity/`。
**方向声明**：leo「要的是双环方案产生的引力场，不是 FRC」——`design-two-flow-ring-axial.md`
（磁位形那条线）页头已加注，**量没错但不是目标**，尤其别拿它的半径选择去定装置几何。

- **判据**：`η = 1 − Q_A(C_Cu+C_H)/Q_A(C_Cu)`（GCA2：A 内引力关闭 ⟺ Q_A=0）；`μ_n = 1−(1−η)^n`；引力响应 `(1−η)^n`。
- **地基**：同半径+反环量 ⟹ 空间流**精确抵消**（Q_A = 0.000e+00，**η = 1.000000**，一步 μ=1）。
- **★ 关键数字**：按 FRC 挑的几何（R_Cu=0.60 / R_H=0.35）在目标区 **η = −20.53 < 0**
  —— 加 H 环反而让空间流更不均匀，**一点引力关闭都没有**。
- **η(R_H) 单峰**、峰在 R_H = R_Cu（径向匹配是充要条件）。
- **容差**：径向 |ΔR| ≤ **0.240 m**（η≥0.5；η≥0.9 需 ≤ 0.060 m）；轴向 d ≤ **0.05 m**（更苛刻）。
- **设计规则后果**：**半径不该按 FRC 挑**（FRC 要不同半径、引力要同半径）。

**状态**：只到「设计与验收依据」——**未接进 `internal/design`**（要接须走契约变更）、**不进任何世界**。
