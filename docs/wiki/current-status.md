## 诚实边界（必须与上面的数字一起读）

1. **最优解很可能是不可造的位形。** D9857 把一圈 `a=0.10 m`、`1.78 MA` 的线圈放在距中场采样点
   **4.196 mm** 处——落在求解器 5 mm 的 `alpha2` 钳位半径内。目标函数目前**没有"导体到约束区域的净空"约束**，
   所以它合法地把导体贴到打分点旁边换场强。任何引用 `1.381419` 的场合都必须带这句限定。
2. **热启动的增益在 1000 次预算下不显著**（1.3073 vs 1.3033，后者方差还更小）。
   "继承设计知识值多少钱"在 Phase 0 的答案是：**这个预算下 ≈ 0**。
3. **人工基线在这个盒子里是弱基线**：随机搜索平均 8 次评估就追平它。它赢在"是个真装置"，不赢在指标。
4. 真空静磁模型：没有等离子体、没有平衡、没有有限 β、没有涡流。它回答"这个线圈配置的场结构好不好"，
   **不回答**"这台装置能不能聚变"。
5. `sign_agreement` 恒为 1.000 是**复制证据不是质量分**——规则是由"每个 run 同号"硬过滤出来的，
   该字段存在的意义只是核对过滤没被绕过。

## 世界协议（2026-09-27，P0，与 headless 的边界）

契约：`docs/world-protocol.md`（**冻结文本**，改动即协议版本变更）。它冻结的是**线协议**，不是新物理：

- **JSONL / stdio**，一行一请求一行一响应；stdout 只放协议行（噪声会让客户端读到错位的响应 = 静默损坏）。

- **语义唯一权威是 `internal/rlenv`**：协议只搬运与校验，不在这里加 shaping、惩罚或归一化。
- **门 G18（三条一起判）**：Go 逐字节回放 / Python 客户端逐字节回放（跨语言证据）/ 把改坏的 hello 喂给客户端必须非零退出。证据 `testdata/world_trace_golden.jsonl`（8 行 / 响应 3635 字节，由 recorder 生成；抽请求重录 **`cmp` 逐字节相同**）。

**构造性非零（不是赌的）**：取 `(flatten(A), update_mu)` —— 先抹平再更新：η=1 ⟹ `μ'=1`（TD12+TD5）；
先更新再抹平：η₀=0 ⟹ `μ'` 不动。顺序差就是 `(1−μ)`，与 TD15/TD16 的闭式 `(1−μ)(1−η_before)` 一致。

**实测**（225 对 = 5 seed × 3 前缀 × 15 对）：控制组 `max|A| = 1.42e-14 ≤ 1e-12`（尺子读数成立）；
`max|A_meas − A_pred| = 4.44e-16`（容差 1e-12）；定理说非零的 85 对 `min|A| = 5.23e-6`（最大 1.25）；
定理说可交换的 140 对 `max|A| = 0`（精确零）；**0 对出现「定理与读数不一致」**。

**顺带修掉一个真缺陷**：Python 回放原先把世界 stdout 解码成 `str` 再比 —— **字符级**，
而契约 §2 要的是**字节级**。修前它数出 10038「bytes」（实为字符）与 Go 的 10048 不一致，两个数本身就是报警。
