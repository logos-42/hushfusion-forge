## 3. 构造性非零（这是这份候选最强的地方）

取一对动作 `(flatten(A), update_mu)`：

- 次序① 先抹平再更新：抹平一次 ⟹ `Q_A(v)=0` ⟹ η=1 ⟹ **μ' = 1**（TD12 + TD5）；
- 次序② 先更新再抹平：`η₀ = 1 − Q_A(v₀)/Q_A(v₀) = 0` ⟹ **μ' = μ 不动**。

⇒ 顺序差在 μ 上就是 `(1−μ)`，与 TD15/TD16 的闭式 `(1−μ)(1−η_before)` 一致（η_before=0）。
目标函数读 μ（窗口余量 / 锁定因子 / 可关闭性，单调于 μ）⟹ **A ≠ 0 是构造出来的，不是赌出来的**。
层状对（不交/嵌套）走 GCA6a/b：交换子恒为 0 ⟹ A 必须**精确为 0** —— 这给了"该为零"的一侧对照。

## 4. 已实测（第一片落地）

- 控制组（旧世界的参数盒语义，无夹取）：`max|A| = 1.42e-14 ≤ 1e-12` ⟹ **尺子读数成立**。
- 交换子世界（225 对无序动作对 = 5 seed × 3 前缀 × 15 对）：
  `max|A_meas − A_pred| = 4.44e-16`（容差 1e-12）—— 实测与定理**一致到浮点噪声**；
  定理说必须非零的 85 对 `min|A| = 5.23e-6`（最大 1.25）；定理说可交换的 140 对 `max|A| = 0`（精确零）；
  **0 对出现"定理与读数不一致"**。
- 协议纪律：`testdata/world_trace_golden_mu.jsonl`（17 行）Go / Python 两侧**各 10048 字节逐字节**回放。

  换一组权重会不会改变结论，**没有测**。
