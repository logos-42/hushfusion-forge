# 实验 C —— 跨 spec 的 Knowledge Survival（Phase C）

**结论先行：记忆（Champion）跨任务成立，规则（Rule）跨任务失效。**
这是你文档 Phase C 预言分叉的精确复现：当前 design_rules.md 的规则是 **task-specific heuristic**，
而"记住好设计"是可迁移的知识。

## 0. 这是什么

实验 A 证明"知识复用降低未来成本"，B 证明"冠军主导、规则弱"。C 追问第三层（文档 Phase C）：

> **S0 学到的知识，在换了任务（S1/S2/S3）后还成立吗？**

S0 = runs/phase1（基准 spec，4 线圈）。学到两种知识：
- **Champion**：S0 的最优设计（evolution_knowledge 播种）
- **Rule**：S0 挖的 cost 规则（"降 I_0/I_1/I_3"）

在三个扰动态下重跑（保持 S0 的知识来源不变，只换 spec）：

| 变体 | 扰动 | 对应文档 |

| S1_geometry | `z_cell=0.60m`（线圈轴向间距） | S1 不同 coil spacing |

## 3. 三条结论（诚实读出）

**(1) Champion（记忆）跨任务成立**：S0 最优继承到 S1/S2/S3 **全部 9 组领先冷搜索**（+0.02~+0.70）。
小预算尤其强（50 档 +0.59~+0.70），随 budget 收敛（冷搜索自己追上）。从不落后。
⟹ **"记住好设计"是可迁移的知识** —— 即使任务几何/目标变了，上一轮最优仍是最好的起点。

**(2) Rule（规则）跨任务失效**：rule−cold 在 9 组里 7 组为负或 ~0（仅 2 组 +0.03~0.06）。
⟹ **cost 规则是 task-specific heuristic**，不是通用设计规律。换任务后它不帮助、有时还拖累。

**(3) 精确复现文档分叉**：正是你 Phase C 预言的第一支 ——
`Rule → S1/S2/S3 无效` ⟹ 当前规则只是 task-specific；而 Champion 有效 ⟹ 记忆跨任务。
**design_rules.md 目前不是先验知识，是"冠军点的副产品"；真正的跨任务规律还没被抽象出来。**

## 4. 为什么 Champion 跨任务、Rule 不跨

S0 的最优设计之所以在 S1/S2/S3 仍好，是因为**最优设计的"形状"（哪个线圈大电流小、大致布局）
本身携带了大部分"好"的信息** —— 换任务后它仍是可行域里的好点。而 cost 规则"降电流"是
S0 目标函数里"成本压低"这一**单一权衡轴**的产物，换任务后目标函数权重/几何变了，
这条轴不再主导。

⟹ 要有**真正的跨任务规律**，需要挖"参数组合 → score"（多变量、含权衡）而非"单参数 → 单项"。
这指向 Phase D（主动选实验）之前该做的：把规则从"单项 Spearman"升级为"多变量/帕累托"。
