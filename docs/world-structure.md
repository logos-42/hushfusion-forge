# Forge World 的时序结构判据与计量协议（P1 冻结文本）

> **这份文本冻的是判据,不是实现。** 实现与本文不一致时,**文本是权威**。
> 它回答一个问题:**Forge 的设计空间,够不够格用来检验时间抽象(Options)?**
> 配套:`docs/world-protocol.md`(线协议 v2 的增补在那边)、`选项验证技能` 的三道门。

---

## 0. 为什么要有这份文本

headless 最硬的负结果是「Options 在 `lm4` 上显著有害」,后来自己推翻了它:那次测的是 **benchmark 的性质**——
`lm4` 的不对称性 `A ≡ 0.0000`(bootstrap CI `[0,0]`),动作完全可交换,**没有多步规划空间**,
任何类别的 option 都不可能有收益,与实现无关。

Forge 现在的 `rlenv`(`Env`,单步)处在**同一个位置**:状态 = 当前参数,动作 = 改参数,奖励 = 当场打分,
而分数只由**最终参数**决定 ⇒ 任意两条改法只要走到同一点就同分 ⇒ **动作可交换**(`A ≡ 0` 在结构上成立)。
所以在 P0 之后直接接 Options,就是第二次重演 `lm4`。

**P1 的全部任务就是:先让世界有可被抽象的顺序依赖,并证明它有。证明不了,就不许往接 Options。**
(黑名单第 1 条:`A ≡ 0` 的基准上对 option 下任何结论。)

## 1. 判据量:`A`(不对称性)—— 用 headless 那把尺,不改定义

定义逐字沿用 `选项验证技能` §2 门①:

```
I(a,b) = 效(b | 先做 a) − 效(b | 不做 a)
A(a,b) = I(a,b) − I(b,a)
```

- `A ≡ 0`(与噪声同量级、CI 含 0)⇒ 动作可交换 ⇒ **无时序结构**;
- `|A|` 显著非零且比例可观 ⇒ 有时序结构 ⇒ 可以用来检验 option。

**在 Forge 世界里的具体化(必须严格按此,不许换一个更方便的量):**

```
eff(b | prefix a) = score( 世界走 a 再走 b 之后的那个设计 ) − score( 世界只走 a 之后的那个设计 )
I(a,b)            = eff(b | a) − eff(b | ∅)
A(a,b)            = I(a,b) − I(b,a)
```

- `score` = **真目标函数**(`internal/objective` 的原始分数),**不是**世界整形过的 `reward`。
  用整形后的 reward 去测结构,等于把结构自己塞进去再测出来 —— 循环论证,违规。
- 走法必须经过**世界的真转移**(夹取、前提门、换源),不是解析地改参数。
- `∅` = 不做事(空前缀),`eff(b|∅)` 就是单独做 b 的增量。

**数学上等价的说法**:`A` 是 score 对两个动作的**混合差分**。
只要分数在两个动作之间是**可加可分**的(`f(θ+d₁+d₂) = f(θ+d₁) + f(θ+d₂) − f(θ)` 这类),就有 `A ≡ 0`。
所以 `A ≠ 0` 精确地等价于「分数在两个动作之间**不可分离**」——这正是「顺序有意义」的定义。

## 2. 时序结构从哪来(全部用已存在的真量,**不新增物理**)

| 规则 | 内容 | 是 A 的来源吗 |
|:--|:--|:--|
| **R1 预算** | episode 给整数**步数预算**;`truncated = (已用步数 ≥ 预算)`。奖励里扣一项真代价:`reward = Δscore − λ_cost · max(0, Δcost_proxy) / cost(θ_prev)` | **不是**。它只改变「走多远」,不改变顺序 —— 沿路径求和会望远镜消掉。写在这里是为了**不许把它冒充成结构** |
| **R2 边界夹取的非交换性** | 动作是**当前**参数上的增量,结果夹进盒子;物理层自己的 θ-依赖钳位(近导线 5 mm 的 `alpha2` 钳位 = 已冻结的官方定义、线圈峰场天花板、μ 窗口边界)都参与 | **是**。夹取生效时 `clip(clip(θ+d₁)+d₂) ≠ clip(clip(θ+d₂)+d₁)`。仓库已知的真现象:机器最优解贴在**距打分点 4.196 mm** 这个边界上 |
| **R3 前提门** | 若当前设计处在「夹取区」(线圈距打分点 < 5 mm,或 `B_coil_max_T` 超材料天花板),则**只接受把设计移出该区的动作**,其余动作被拒:`info.rejected=true`,**仍消耗一步预算** | **是**(R2 的强化:先修前提再调参 ≠ 先调参再修前提) |
| **R4 换场源** | `set_source` 在 episode 中途换真源(`MATBG_N2_perp` = 0.12 T / `MATBG_N2_par` = 1.6 T,两者都是上游真源),**重新求值**并重算死活判据与 μ 窗口余量 | **是**(最强的来源:同一个 θ 在两个源下的死活判决相反 ⇒ R3 的开关状态随之翻转 ⇒ 先调参后换源 ≠ 先换源后调参)。消耗 1 预算单位 |
| **R5 终止** | `terminated = (score ≥ regime.target)`(**游戏规则声明,不是物理**) | 不是;它让四档 regime 的终止原因可分辨 |

**观测必须把历史装进去**(否则「有结构」在 agent 眼里不存在):v2 的 obs = v1 的 19 维
`+ budget_remaining_norm + depth_norm + residuals[3] + source_onehot[2]`。
`residuals[3]` = 三个**真**约束余量(死活判据余量 / μ 窗口余量 / 导体场天花板余量),
全部来自 `internal/design` 的闭式解;**不许**在这里现场发明约束。

**诚实边界**:R1/R5 是游戏规则,R2/R3/R4 是真现象的显式化。**本版本仍然不新增物理**:
物理层(`internal/design` / `internal/physics`)一行不动,世界只在它的输出上做顺序。

## 3. 四档 regime(必须互相可区分)

`{perp, par} × {tight, loose}`:

| 档 | source | 步数预算 | target |
|:--|:--|:--|:--|
| tight-perp | `MATBG_N2_perp` | 8 | 1.0 |
| loose-perp | `MATBG_N2_perp` | 24 | 1.0 |
| tight-par | `MATBG_N2_par` | 8 | 1.0 |
| loose-par | `MATBG_N2_par` | 24 | 1.0 |

**每档的特征向量**(必须两两可区分,至少 3/4 档):

`[argmax 动作索引, 该档可达的最高真分数, 达到最高分所用步数, 终止原因]`

四档全同 ⇒ regime 参数没进入动力学 ⇒ **门红**(说明我们只是换了几个常数)。

## 4. 预注册阈值(先写死,**不许**看了结果再调)

计量:`K` 个真动作(从动作盒里均匀取,显式 seed),全部 `K(K−1)/2` 配对,≥5 个 seed,报告
`median|A|`、`|A|` 超阈比例、bootstrap 95% CI。参照全量程 = `1.672`
(人工基线 `−0.2905708161` → 机器最优 `1.381419` 的落差,两个数都是实测锚点)。

| 档 | 判据 | 结论 / 处置 |
|:--|:--|:--|
| **零档** | `A ≡ 0`(≤1e-12,或 CI 含 0) | **G19 红**。判定「本世界规则下设计空间仍可交换」,**P2/P3 不启动**;转 **P4**(把已验证的搜索算子放回 optimization),或重新设计世界语义 |
| **弱档** | `0 < median|A| < 0.05 × 1.672 = 0.0836` | 记录,**P2 不启动**。先改世界语义(让 R2/R3/R4 真正咬住),再重测 |
| **强档** | 某 regime `median|A| ≥ 0.0836` 且 CI 不含 0 且在 ≥3/5 seed 上复现 | **允许进 P2**(预测层 GVF/Horde)。这仍然**不**等于「options 有用」——那要 P3 的 K1 四档矩阵 + 消融 |

**控制组(尺子必须能读出 0,这一步不过就是尺子坏,不是世界没结构)**:
同一批 `K` 个动作喂给 **v1 的 `Env` 单步语义**(绝对参数、无前提门、不换源、无夹取)
⇒ `A` 必须 **deg 0**(≤1e-12)。控制组不零 ⇒ **G19 红**,先修计量脚本。

## 6. 黑名单(本项目实测教训,不许再犯)

- ❌ 在 `A ≡ 0` 的世界上对 option 下任何结论(`lm4` 那一课);
- ❌ 用整形后的 `reward` 当 `A` 的「效果」量(循环论证);
- ❌ 把 R1(预算)冒充成时序结构的来源;
- ❌ 看到弱档/零档就去调阈值或换动作集合(那是把结果调成想要的);
- ❌ 四档 regime 只换常数、不换动力学,却报「已可区分」;
- ❌ 把「结构存在」写成「options 有用」(P3 的事,且 P3 要消融)。

## 7. 勘误与裁决（2026-09-27 实测后追写，**不改上面正文,以本节为准**）

P1 的计量跑出来了,结果是**弱档**(见下)。计量同时**证伪了本文档正文里的四处说法**。
按仓库规矩(不许美化、不许把结果调成想要的),勘误写在这里,而不是回去把正文改得好看。

### 7.1 实测结论(一句话)

**弱档 ⇒ 按 §4 的预注册处置: P2 不启动。** 数字:池化 140 对/档,`median|A| = 0.050246 < 0.0836`,
超阈比例 `64/140 = 0.4571`,`median|A|` 的 CI95 `[0.00519, 0.22254]`(不含 0)但**逐 seed 只有 2/5 达阈**;
四档只给出 **2 个**互不相同的特征向量(< 预注册的 3/4)⇒ G19c 红。
**没有调阈值、没有换动作集合、没有挑初始点。**

### 7.2 勘误一（最重的一条:正文 §0 的前提就是错的）

正文 §0 说「Forge 的 `rlenv` 处在同一个位置,`A ≡ 0` **在结构上成立**」。**实测不成立。**

- `A ≡ 0` 只在**无夹取的理想化**下成立(控制组:绝对参数、无前提门、不换源、无夹取 ⇒ `max|A| = 1.42e-14`)。
- **真实世界里 `A` 已经非零**:字面 v1 `Env`(带夹取、同一批动作与 seed)`median|A| = 0.0430804`,
  `frac ≥ 0.0836 = 0.4429`。也就是说 —— **夹取(R2)一个人就贡献了全部的量**。
- 所以 P1 的问题不是「世界有没有结构」,而是「**已有的结构够不够格检验 Options**」。
  按预注册的 5% 全量程这条线:**不够**(3% 量级)。

### 7.3 勘误二（R4 不是目标函数的来源,正文把它写成"最强的来源"是错的）

正文 §2 表把 R4(换场源)称为**最强的来源**。实测:四档的 `A` 分布**逐位相同** ⇒ 源不进动力学。原因在实现里可查:
`scoreV2` 只调 scorer,**不带源**;源只进 `resid_*` 三个余量与 `source_onehot`。这不是实现的偷懒 ——
设计层的场源(0.12 T / 1.6 T)要进**目标函数**,就得把设计层的场物理接进 rlenv 的评分,那才叫**新增物理**,v2 明文禁止。

⇒ 裁决:R4 降级为「**进观测、不进目标**」。它要成为 `A` 的来源,只能等一次显式的物理接线(协议 v3 级别的事),
在此之前不许拿它当"结构"说事。

### 7.4 勘误三（R3 的"夹取区"定义,按设计层真门读会退化成世界常数）

按设计层的真门 `B_coil_max ≤ min(spec.CoilFieldLimit, B_cap)` 读:访问到的 925 个设计里
`B_coil_max_T` 最小值 **3.2 T**(含自场 `3.1416 T`),**100% 超任一源的 `B_cap`** ⇒ 区**恒开** ⇒
「只接受移出该区的动作」退化成「世界常数」,它不是前提门。

⇒ 裁决:**R3 的"夹取区"收敛为「线圈距打分点 < 5 mm 的 `alpha2` 钳位区」** —— 这是仓库已冻结的**真现象**
(CONTRACT §9 的官方定义),也是机器最优解实际踩着的那个边界(4.196 mm)。
天花板作为**观测余量**(`resid_coil_ceiling`)保留,但**不作为前提门条件**。
依据:一个恒真的前提不是前提。实测 R3 只拒了 5/≈720 步(40 个 seed 里 3 个起点在区内)——
**它现在几乎不咬人,这正是弱档的两个原因之一**(另一个是 R2 的量级)。

### 7.5 勘误四（G19b 的门语义写错了:门不能把"结构未证明"印成绿）

§5 写的是「零档即红」,于是**弱档**会让 `G19b` 印 `pass`,而 §4 又说弱档「P2 不启动」——
合起来就是:**门绿着,结论却是"不许往下走"**。这正是"假绿比没有门更伤"。

⇒ 裁决:**只有强档 `G19b` 为 pass;弱档与零档都红**(红的理由不同,输出里必须写明是哪一档 + "P2 不启动")。
本轮的判定不变(整体仍红)。

### 7.6 勘误五（特征向量的判定过程没冻结）

冻结:固定 `K` 动作序列、逐步取本轮最优、取整 episode 的最优一步。
并明确它的**声称范围**:G19c 只证明「四档在**状态**层面可区分」,
**不**证明「在转移层面可区分」—— 后者是 G19b(`A`)的活。四档只换常数不换动力学时,这里就该红。

### 7.7 这一节之后,通往 P2 的两条路(由父线拍板,不是实现线能选的)

1. **让 R2/R3 真正咬住,再重测**(§4 弱档的预注册处置):regime 的初始状态分布要覆盖**真钳位区**
   (机器最优解自己就在 4.196 mm 那个边界上,agent 搜索时也一定会走到那里),
   而不是 40 个 seed 里只有 3 个落在区内。**阈值一个字不许动**,并且必须**同时报**"内部起点"与"边界起点"两套数。
2. **承认这条路不通**:若 `rlenv` 这一层本质上只是「带边界的 payoff landscape」,
   那就按 §4 零档/弱档的处置转 **P4**(把已验证的搜索算子放回 `optimization`),
   并如实记下:**「Forge 世界够不够格检验 Options」这一问,在本层物理下答案是"不够"**。
