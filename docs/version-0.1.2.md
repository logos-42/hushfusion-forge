# Forge 0.1.2 —— 系统层收口（合同变更）

> 本文件是 **0.1.2 这一版的契约**。它按仓库纪律先于代码写：凡是会改变
> 「一个设计的分数」或「世界的一条动力学」的东西，都先在这里定义口径、判据与**死法**，
> 再由实现去满足它。CONTRACT.md §5/§6 是它的镜像；两者冲突时以本文件 + `scripts/verify.sh` 为准。

---

## 0. 为什么要有 0.1.2（版本语义）

0.1.0 把 Phase 0 做完了：机器能在**旧目标函数**下赢人工基线（Δ = +1.672），
但那个最优点是一个**不可造的退化解**（一圈 `a=0.10 m`、`1.78 MA` 的导体被放在距中场采样点
**4.196 mm** 处，落在求解器 5 mm 的 `alpha2` 钳位半径内）。旧目标函数**没有**任何一项
阻止这件事——它只惩罚导体自身场、线圈间距、以及「不像镜」。详见 PLAN.md §3 与
`docs/wiki/current-status.md` 的诚实边界。

因此 0.1.2 要做的不是加一个功能，而是**把「可造性」补进判据**，并顺手把两处
系统层的不自洽收口：

| # | 收口项 | 一句话 |
|:--|:--|:--|
| A | **可造性进目标函数** | 导体到约束区域的净空成为一条惩罚项；退化解被踢出最优位 |
| B | **世界语义重做** | v2 世界把 L3 判决压成了观测却没接进转移 ⟹ 分档逐位相同、G19 弱档；把动力学接到 L3 |
| C | **版本与发版模型** | 0.1.0 → 0.1.2；版本号从此有**定义**（见 §3），不再是一个随手加的字符串 |

**这不是新物理**：A 用的是已有的几何与已有的罚项形状；B 是复用已被 G17 锚定的
`internal/design` 判决，不是新增物理。

**版本史（写清，免得问「为什么不是 0.1.1」）**：同一时间另一条线把聚变计划重编为 v2
（`docs/wiki/fusion-program-roadmap-v2.md`：可复用制造系统 + 五步工程法 + 物理判决漏斗），
**只改文档、不改判据** —— 那一轮记为 **0.1.1**。本版 **0.1.2** 是**判据变更**，接在它后面；
两轮合起来才是这一版的实际内容（计划换了组织方式，判据多了一条可造性）。

**本版只交付 A 与 C。** B（世界语义重做）的**方案、判据与死法已在本文件 §2 预注册**，
但**代码未动** —— 所以 G19 的状态与 0.1.0 相同：**红，且红为设计所许**。

## 1. A：可造性（clearance）—— 口径先钉死

### 1.1 为什么是「净空」而不是别的

退化解的本质是：**目标函数合法地把导体贴到打分点旁边换场强**。
要排除它，判据必须落在**导体与约束区域的几何关系**上，而不是落在场值上
（场值正是它作弊换来的东西）。所以判据 = 净空。

### 1.2 三个定义（口径，一个字都不含糊）

```text
约束区域 R_cell := { (r, z) : 0 <= r <= spec.RPlasma, |z| <= spec.ZCell }
                    —— 「等离子体所在的中心元胞」。它与 volume_good 的采样区域**同一口径**
                    （不是中场采样窗口 ZMid：ZMid 只是 B_mid 的取样窗，不是等离子体范围）。

导体面           := 丝环 (r_k, z_k) 起、minor 半径 spec.TPack/2 的圆环面。
                    丝环是 v0.1 的场模型（Coil 只有 radius/z/current），
                    TPack 已经在 SelfField 里表征绕组包厚度，这里复用同一个量。
                    这是**模型选择**，不是推导：v0.1 没有绕组包的离散几何。

净空 c_k          := dist((r_k, z_k), R_cell) − spec.TPack/2      [m]
                    **可以有符号**：c_k < 0 = 导体已侵入约束区域。
```

`dist` 有闭式解，因为 `R_cell` 在柱坐标下是乘积区域（绕轴对称 + (r,z) 可分离）：

```text
dist((a,z0), R_cell) = sqrt( max(0, a − RPlasma)^2 + max(0, |z0| − ZCell)^2 )      （精确）
```

### 1.3 度量与罚项

```text
metrics.min_clearance_m := min_k c_k                       （新冻结 metrics 键；分母是「最小净空」）
penalties.clearance     := max(0, (spec.MinClearance − min_clearance_m) / spec.MinClearance)
```

形状与已有三条罚项**同族**（都是 `max(0, (允许 − 实际)/允许)`），
所以 `score = Σ weighted − w_penalty · Σ penalties` 的逐位可审计性不变
（`penaltyOrder` 里加一项，顺序仍然是冻结的字面量）。

### 1.4 `MinClearance` 的取值：0.05 m —— 说清它是判断，不是物理

`MinClearance = 0.05`（与 `MinCoilSep = 0.05`、`TPack = 0.05` 同量级）。
**与 Weights 同性质：工程判断，不是物理。** 它住在 `internal/config/config.go`（唯一真源），
连同这条注释一起，好让任何人能质疑并重设它。

它必须满足的一条硬约束（**这就是它的判据**）：

> **人工基线在 `MinClearance = 0.05` 下必须仍然是可行的**（`clearance` 罚项 = 0）。

否则「机器打败人类」会退化成「比谁的基线更不可造」。实测：基线最靠近约束区域的是两圈
镜像喉部 `(r=0.30, |z|=1.00)`，`dist = sqrt(0.15² + 0.20²) = 0.25`，
`c = 0.25 − 0.025 = 0.225 m ≥ 0.05` ⟹ 罚项 **0.0**，可行。

### 1.5 判据、反事实与死法

| | 内容 |
|:--|:--|
| **判据** | 0.1.0 的最优解 D9857 在 0.1.2 下必须**变不可行**且被显著惩罚；人工基线的净空罚项必须恰为 0 |
| **反事实** | 同一元组（budget 1000 × seeds 0,1,2）跨版本对比：`Δ_0.1.0 = +1.672` vs `Δ_0.1.2 = ?` —— 这就是「物理约束值多少钱」的第一次测量 |
| **死法** | 若新约束只是把最优点挪到 4.999 cm 而不改变任何结构（即只在钳位边界上蹭），则这条约束**没有解决它要解决的问题**，必须换判据（例如改成「导体到约束区域的净空」以外的可造性口径），**不许**靠调 `MinClearance` 变绿 |
| **不许** | 不许为了让 Δ 好看而调 `MinClearance`；不许把 Phase 0 的 registry 重跑覆盖（它是 0.1.0 的证据，不是脏数据） |

## 2. B：世界语义重做 —— 把动力学接到 L3

### 2.1 实测的病灶（不需要新测量，G19 已经写在 `docs/world-structure-p1.md`）

- 四档 A 分布**逐位相同** ⟹ 源（`perp`/`par`）与预算（8/24）**都没进两步行走的动力学**；
- `A` 全部来自 **R2 夹取**（≈55% 的步撞盒子/钳位）；
- **R3 前提门几乎不咬**（720 步里只拒 5 步）；**R4 换源不进目标函数**（`scoreV2` 不把源传给 scorer）。

### 2.2 重做方案（复用，不新增物理）

把 v2 世界的**转移**接到 `internal/design.Review`（L3）：

```text
现状   : 状态 = 参数向量; 动作 = 改参数; 奖励 = 当场 score（只含参数 → 场 → 标量）
改成   : 状态 = 参数向量 + 该设计的 L3 判决（哪道门挡路）;
         动作 = 改参数（可能改变「哪道门挡路」）;
         奖励 = score + 判决项（门状态跃迁的势）
```

依据是仓库自己已有的结论（`docs/wiki/current-status.md`「结构在哪一层」表）：
换源改变的是**哪道门挡路**（`a=0.2` 面外 0.12 T ⟹ `death` 与 `mu_window` 死；
面内 1.6 T ⟹ `mu_window` 开但 `coil_load` 死），而每道门要动的**参数完全不同** ⟹
**顺序在这里是真的**。L3 已实现、已被 G17 用上游锚点钉住 ⟹ 这是**接进来**，不是新物理。

### 2.3 判据与阈值纪律

- **阈值一个字不许动**这句仍然有效，但它的意思是「不许为了让门变绿去改数字」，
  **不是**「不许换层」。按 `docs/world-structure.md` 的既有规则：**换层必须重新预注册阈值**
  （全量程参照按该层自己的落差重算，不许沿用 L2 的 1.672），并把这份预注册写成新的一节，
  与旧的那份并列存档、标明哪一份对哪一层有效。
- 三条子门（尺子自检 / 结构门 / 四档可区分）判据形状不变。
- **G19 只有在实测量出来之后才是绿的**：不许靠调 `MinClearance` / 预算 / 步数把它调绿。

### 2.4 死法

> 若接进 L3 之后四档仍然逐位相同（即源**还是**没进动力学），则「结构在 L3」这个判断被否证，
> 本层承认只是带边界的 payoff landscape，转到 `PLAN.md` 的 P4（承认并记录），
> **不许**再堆第三层来救它。

## 3. C：版本与发版模型（版本号从此有定义）

```text
MAJOR.MINOR.PATCH
  MAJOR  冻结契约的**断裂**性变更（改冻结签名/类型/JSON tag 的语义、删字段）
  MINOR  新增能力（新命令/新世界/新层），旧证据仍可解释
  PATCH  **改判据本身** —— 任何会让同一个设计得到不同分数的改动（含目标函数加/改罚项）
```

⟹ **0.1.0 → 0.1.2 是 PATCH**：契约不断裂，但**判据变了**，所以 `runs/` 里的证据必须能被
按版本读出来（见下）。

### 3.1 发版时必须同步的清单（机器可查的部分由 `verify.sh` 收口）

| # | 位置 | 内容 |
|:--|:--|:--|
| 1 | `cmd/forge/main.go` | `const Version` |
| 2 | `testdata/golden_*.json` | 由 **Python oracle** 重新产出（`--emit-golden` + `--force`），并由 Go 侧复核 |
| 3 | `testdata/golden_spec.json` | `config.Spec.AsMap()` 的**新**键集合（schema parity） |
| 4 | `CONTRACT.md` §5 | 数值锚点表（凡变的数都要写新值 + 旧值） |
| 5 | `CONTRACT.md` §6 + `scripts/verify.sh` | 门表镜像与新门 |
| 6 | `README.md` / `README.en.md` | 版本与判据变化 |
| 7 | `docs/wiki/current-status.md` `log.md` `index.md` | wiki-first 三件套 |
| 8 | `CHANGELOG.md` | 本版**判据变化 + 对旧证据的影响**（不写流水账） |

### 3.2 旧证据的定位（写死）

- `runs/phase0/` 是 **0.1.0 判据下的证据**，**永不重跑覆盖**。引用它时必须带 `v0.1.0` 字样。
- `runs/phase1/` 是 **0.1.2 判据下的同元组重跑**（budget 1000 × seeds 0,1,2）。
- **跨版本对比是唯一合法的消融轴**：同一元组、同一算法、同一 seed，只有判据不同。
  这就是为什么 0.1.2 不再额外加一个 `--clearance=false` 开关——
  **版本号本身是那个开关**，且两侧都被归档、可逐位复现。

## 5. 新增门 G23（可造性门）—— 它抓什么失败模式

```text
G23 = 三条一起判：
  (a) 基线可行且 clearance 罚项精确为 0   → 抓「约束把真装置也判死」
  (b) 0.1.0 的最优退化解 D9857 在 0.1.2 下 infeasible 且 penalties.clearance > 0
      → 抓「约束没咬住它要咬的东西」（这正是本轮存在的理由）
  (c) min_clearance_m 的闭式解 == 暴力采样半径扫描（相对 < 1e-9）
      → 抓「几何算错」（几何是新的唯一一处新数学，必须有独立路径）
```

**没有 (b) 这道门，「退化解被踢出去了」就只是一次性观测。**

## 6. 诚实边界（写死）

- v0.1.2 仍是**真空静磁学**：这层没有等离子体、平衡、有限 β、涡流。可造性约束**不是**
  工程可行性审查，它是**几何净空**——一个必要条件，远不是充分条件
  （没算支撑结构、冷质量、装配公差、失超保护）。
- `MinClearance = 0.05`、`TPack/2` 作导体面半径，**都是模型选择/工程判断**，不是推导。
- B 项（世界语义重做）**不新增物理**；它把已实现、已被 G17 锚定的 L3 判决接进动力学。
  它给出的结构是「设计流程层」的顺序，**不等于** options 对真实装置有用。
- 本版**不**接硬件四轴（装置/诊断/建造/排期）：那要等上游把环几何与设备清单填好；
  `world_feed.json` 里 7 个缺口槽位取值仍为 `null`，**缺口处不填预设值**。
- 与上游物理的关系：本层**不算 μ**（μ 的主动产生 = 上游未决的第二个标度缺口，
  见上游 `docs/wiki/theory-scale-gap-anatomy.md`），只算「给定 μ 能维持多少步、需要多大的场」。
