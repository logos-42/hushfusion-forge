# T-01 验收标准 —— G19 世界语义重做（B 项）

> 状态：active（2026-10-17 起）｜ 预注册依据：`docs/version-0.1.2.md` §2（判据与死法已先于代码写死）

## 1. 背景（一句话）

v2 世界把 L3 判决（`internal/design.Review` 的六道门）压成了观测却没接进转移 ⟹ 四档 A 分布逐位相同、G19 弱档。本任务把世界的**动力学**接到 L3——复用已被 G17 锚定的实现，**不新增物理**。

## 2. 验收标准（三条子门，判据形状不变）

### 2a. 尺子自检（控制组）

- [ ] 控制组（旧世界参数盒语义、无夹取、不换源）`max|A| ≤ 1e-12`（实测基线 1.42e-14）。
- 判据：**控制组读不出 0，就是尺子坏**，实验组数字一律不算。

### 2b. 结构门（档位判定）

- [ ] 换层后**重新预注册阈值**：全量程参照按 L3 自己的落差重算（**不许沿用 L2 的 1.672**），预注册写进新的一节，与旧阈值并列存档、标明哪一份对哪一层有效。
- [ ] 新档位必须是**强档**（P1 规则：弱档 ⟹ P2 不启动）。
- [ ] 逐 seed 复现（≥3 seeds，最好 5）。

### 2c. 四档可区分

- [ ] 源（perp/par）与预算（8/24）必须**真正进动力学**：四档 A 分布不再逐位相同（特征向量 ≥3/4 档两两可分）。
- [ ] 构造性非零：至少一个动作对由**顺序差闭式预测**（像 mu 世界的 `(1−μ)(1−η_before)`），实测对预测差 ≤ 1e-12。

## 3. 死法（先写死，满足即停止）

- 若接进 L3 后四档仍逐位相同（源**还是**没进动力学）→ 「结构在 L3」被否证，本层承认只是带边界的 payoff landscape，转 `PLAN.md` P4，**不许**再堆第三层救它。
- 不许靠调 `MinClearance` / 预算 / 步数 / 阈值把门调绿。

## 4. 不许项

- 不许改冻结面（`internal/*/api.go` 签名/类型/JSON tag；`testdata/golden_*.json` 数值）——要改走契约变更。
- 不许新增「只在观测里、不进转移」的结构（那是 G19c 的病根）。
- 不许把 G19 的「红为设计所许」改写成「预期绿」。
