# EXPERIMENTS —— 实验与验证记录（证据状态机）

> **状态机（五态）**——任何结论必须按态走，状态转换必须以证据为门槛，不能因为「Agent 说完成了」就前进：
>
> 1. **提出问题**（研究问题、可检验假设、知识边界）
> 2. **形成验证方案**（理论依据、公开数据、对照方法、判据与**死法**——本仓惯例：方案先于代码，如 `docs/version-*.md`）
> 3. **完成可复现测试**（代码能跑、输入/输出/参数/失败条件有记录 → 落盘 `runs/<tag>/`）
> 4. **获得独立反馈**（外部专家 / 公开基准 / 独立 oracle / 多 seed —— 至少一条检查**不依赖被测对象自己**）
> 5. **形成下一阶段决策**（继续 / 修正 / 扩大 / 停止 → 写进 `os/DECISIONS.md`）
>
