# HUSHFUSION North Star

> 本文件回答一个问题：**HUSHFUSION 是什么、不是什么**。方向变更必须先改这里，再改任务。
> 创建：2026-10-17 ｜ 最后确认：2026-10-17

## 使命（一句话）

把科学问题转化为**可验证、可复现、可合作、可持续获得资源**的研究计划——每一条对外结论都必须有独立复现的证据门槛。

## 范围

| 系统 | 包含 | 不包含（边界） |
|:--|:--|:--|
| 研究系统 | 引力场几何描述（三方向）、μ 动力学（Hibs-Physics 上游）、Forge 电磁设计闭环 | 不替上游 Re-derive 物理；上游数字不进源码常量 |
| 工程系统 | Forge（Go 主栈）、**Agent Kernel 主导执行**（Bolloon kernel bridge，G24）、内部设计判决层、世界协议（v1/v2/mu） | 不替 kernel 判「该不该继续」；不给 score 加未登记的功能；冻结面（api.go / golden）不动 |
| 持续学习 | OML 配置推荐器、发育式结构（已收口）、反引力 μ 控制 | 分形/发育的**结构优势**主张已被多 seed 否定，仅在「大网络+收益递减」regime 重启 |
| 合作与资源 | 合作机会池、出版渠道（aiXiv 等）、公开数据基准 | 对外承诺前必须走 DECISIONS.md + leo 亲自确认 |

## 北极星指标（候选，未冻结——每一条都可被独立检验）

1. **被外部独立复验的结论条数**（跨语言 oracle、多 seed、上游锚点、公开数据对照）。
2. **Forge 对真实装置几何的预测能力**：至少一个公开聚变装置/线圈数据基准，我们算的场与发表的场对齐。
3. **一个可验证的引力场预言**：μ 关闭（或 η<0 反证）在实验口径下可测——哪怕结论是「此路不通」，只要可复验，也是产出。

## 防漂移规则

- 方向变更 = 先写 DECISIONS.md（依据/备选/后果），再动任务池。
- 系统建设必须回答：**是否更快获得可靠的物理证据 / 更容易获得外部反馈 / 更有效地获得资源？** 三个答案都是「否」→ 先不做。
- 没有新证据时，不放大叙事（「更勤奋的机器」不是目标，「能产生可靠结果的整体」才是）。
